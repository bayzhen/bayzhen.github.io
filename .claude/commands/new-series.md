请帮我创建一个新的文章系列。

## 步骤

1. **确认信息**：
   - 系列名称（英文，用于目录名）
   - 系列标题（中文）
   - 系列描述
   - 预计文章数量和标题列表

2. **创建目录结构**：
   ```
   articles/{series-name}/
   ├── index.html      # 系列索引页
   └── 01-xxx.html     # 第一篇文章（可选）
   ```

3. **创建索引页**：
   - 参考 `articles/claude-code/index.html` 的结构
   - 包含系列概述
   - 按入门/进阶/高级分类（如适用）

4. **更新导航**：
   - 更新 `articles/index.html` 添加系列入口
   - 更新 `index.html` 首页分类列表

## 输出

创建完成后，列出：
- 创建的文件
- 后续需要添加的文章
