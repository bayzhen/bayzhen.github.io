请检查本网站的所有内部链接是否有效。

## 检查内容

1. **导航链接**：检查所有页面的 `<nav>` 导航栏链接
2. **面包屑链接**：检查 `.breadcrumb` 中的链接
3. **文章导航**：检查 `.nav-links` 上一篇/下一篇链接
4. **索引页链接**：检查文章列表中的链接

## 检查方法

```bash
# 查找所有 href 属性
grep -r "href=" articles/ index.html resume.html

# 检查是否存在对应文件
```

## 输出格式

```
✅ 有效链接数量: XX
❌ 失效链接:
   - 文件: xxx.html, 行: XX, 链接: /path/to/missing
```

如果发现问题，询问我是否需要修复。
