## MODIFIED Requirements

### Requirement: Rich botanical presentation
月光花树 SHALL 具有粗细渐变且自然分叉的枝干、可见但克制的树皮纹理、具有留白和前中后深度的树冠、形状与色彩有变化的叶片、花苞及花朵，并 SHALL 通过分层生长、微风摆动、月光轮廓、露珠微光和花瓣效果建立精致但不拥挤的视觉层次。装饰细节 MUST NOT 遮挡当前互动目标、记忆相框或邀请入口。

#### Scenario: Tree reaches full bloom
- **WHEN** 访客完成树冠生长和三次花苞点击
- **THEN** 页面展示枝干有自然粗细与纹理、树冠疏密有别且不规则对称的完整花树
- **THEN** 叶片、花苞、盛放花朵和月光细节具有可辨识的前后层次
- **THEN** 树冠和花朵保持轻微但不妨碍阅读或操作的环境动画

#### Scenario: Refined tree is viewed on a narrow phone
- **WHEN** 访客在窄屏手机上推进花树流程
- **THEN** 页面保留树干、叶片、花朵和月光层次的主要细节
- **THEN** 次要装饰密度被控制且当前交互目标和记忆相框保持清晰可见
