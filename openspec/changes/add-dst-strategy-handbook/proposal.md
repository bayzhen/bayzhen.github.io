## Why

饥荒联机版（Don't Starve Together）内容量大、机制细、版本会持续更新。当前站点还没有一套面向玩家实战的中文手册型攻略，无法满足“需要时快速查找生存策略、季节规划、角色分工、Boss 准备和资源优先级”的使用场景。

这次 change 先为攻略系列建立 OpenSpec 约束，确保后续写作不是零散文章，而是一套可导航、可查找、可维护的策略指南。

## What Changes

- 新增一个中文文章系列：`dst-strategy-handbook`，定位为《饥荒联机版策略手册》。
- 新增系列首页，说明阅读方式、章节索引、快速查找入口和适用版本说明。
- 新增一组手册文章，覆盖新手开局、四季节奏、基地建设、食物与恢复、角色协作、战斗与 Boss、洞穴与遗迹、后期循环、常见危机处理等主题。
- 在 `_data/series.yml` 注册该系列，使其进入站点系列列表。
- 每篇文章采用一致的“结论先行 + 表格/清单 + 细节解释 + 相关条目”结构，便于快速检索。
- 写作前需要核对当前版本信息，尤其是角色改动、Boss 掉落、物品数值、农场/烹饪/位面机制等 patch-sensitive 内容。
- 不在本 change 中实现站内全文搜索或新的前端交互组件；若后续需要，可以单独提案。

## Capabilities

### New Capabilities

- `dst-strategy-handbook`: 定义饥荒联机版策略手册系列的内容范围、文章结构、快速查找体验、来源核对和维护规则。

### Modified Capabilities

- None.

## Impact

- 新增目录：`articles/dst-strategy-handbook/`
- 新增文章文件：系列首页和多篇 Markdown 攻略文章。
- 修改 `_data/series.yml`：注册新系列标题、描述和排序。
- 可能修改站点导航或索引页，仅限现有系列发现机制无法自动展示新系列时。
- 不新增运行时依赖，不改变 Jekyll 布局系统，不影响现有文章 URL。
