Flomo（浮墨笔记）可以理解成：

> **一个专门记录“灵感碎片”的笔记工具，而不是写长文档的工具。**

它和 Notion、Obsidian、Evernote 最大的区别是：

| 工具       | 核心思想      |
| -------- | --------- |
| Notion   | 构建数据库和知识库 |
| Obsidian | 建立知识网络    |
| Evernote | 收集资料      |
| Flomo    | 快速记录想法    |

Flomo 官方甚至明确表示：

> 重点是帮助你记录更多想法，而不是写更复杂的文章。 ([flomo帮助][1])

---

## 为什么很多人喜欢 Flomo

你有没有这种情况：

* 突然想到一个游戏机制
* 突然想到一个创业点子
* 看书看到一句话
* 和别人聊天获得一个启发

结果：

> 「我等会记下来」

十分钟后忘了。

Flomo解决的就是这个问题。

它打开后几乎就是：

```
想到什么
直接写
发送
结束
```

像发微信一样。 ([Flomo][2])

---

## 它最强的功能

### 1. 卡片笔记

不是文档。

每条记录都是一个独立卡片：

```
ECS最大的优势可能不是性能
而是降低耦合
#游戏开发
#flecs
```

然后下一条：

```
GTA如果用flecs
system数量可能接近1000
#flecs
```

一张卡就是一个想法。

长期积累以后形成知识网络。 ([码造社 | mazaoshe][3])

---

### 2. 每日回顾

这是 Flomo 最有特色的功能。

它会随机把几个月前甚至几年前的卡片翻出来。

例如：

```
2025年7月

AI写代码的问题不是功能实现
而是耦合度
```

突然又出现在你面前。

很多用户认为：

> Flomo的价值不是记录，而是回顾。 ([Flomo][2])

---

### 3. 标签体系

它不用文件夹。

只用：

```
#flecs
#游戏开发
#AI
#创业
```

甚至：

```
#游戏开发/flecs
#游戏开发/渲染
```

这种层级标签。 ([Google Play][4])

---

### 4. 全平台同步

支持：

* Windows（Web/PWA）
* Mac
* Linux（PWA）
* Android
* iPhone
* iPad

同步免费。 ([flomo帮助][5])

---

## 它不适合干什么

Flomo 官方自己承认：

* 不适合写长文章
* 不适合 Markdown
* 不适合 TODO
* 不适合思维导图
* 不适合项目管理 ([Google Play][4])

所以：

### 不适合

* 写设计文档
* 写 openspec
* 写技术方案
* 管理项目

### 适合

* 灵感
* 读书笔记
* 游戏点子
* 碎片思考
* 日记

---

## 对你来说有没有价值？

结合你最近聊的内容（flecs、游戏引擎、自研 ECS、AI 编程），我觉得：

### 非常适合记录

比如：

```
system数量不是关键
entity数量才是关键
#flecs
```

```
vibe coding的问题可能是高耦合
#AI编程
```

```
TerrainResource应该是控制面
ChunkManager应该是数据面
#引擎架构
```

这种一两句话的洞察。

---

### 不适合替代

你的：

* openspec
* design.md
* tasks.md
* 技术文档

这些还是应该放 Git 仓库里。

---

所以如果让我用一句话评价：

> **Notion 像仓库，Obsidian 像图书馆，而 Flomo 像随身携带的灵感收集器。**

对于经常突然冒出游戏设计、ECS架构、AI想法的人，Flomo 确实挺顺手。
