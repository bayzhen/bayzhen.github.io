# 传中迭代总结

来源：`传中迭代_OnePage.xlsx`

## 一句话概括

重建手操传中的“意图 → 落点 → 接球”全链路决策，让玩家蓄力操作真正决定球传到哪、谁去接、球怎么飞，消除当前“传中像随机”的核心体验问题。

## 基础信息

- 需求名：手操传中系统迭代——球追人方案
- 需求等级：A 级
- 上线赛季：待定
- 文档版本：v1.0，待评审
- 设计路径：球追人（Path A）
- 核心原则：踢球帧完成所有决策，轨迹固定，接球人自然到位

## 核心问题

### 1. 传中目标随机感强

- 蓄力时长不影响落点区域和弧线参数。
- 三档传中弧线视觉差异极小。
- 玩家松手后不知道传给谁。
- 操作意图与结果严重脱节。

### 2. 传中球飞到无人区

- 落点基于接球人当前位置计算，没有预测球员移动。
- 退化兜底落点不保证接球人能跑到。
- 球飞行中 AI 接球规则持续运行，接球人可能被重新分配任务而离开落点。

### 3. 接球动作生硬

- 接球人跑位目标每帧由 AI 规则更新，踢球帧没有锁定。
- 初期路径混乱，偶有停步等待。
- 三档传中弧高差异较大，但接球动画候选集没有对应高度档位，动画和球实际到达高度不匹配。

### 4. 守门员出击必胜

- 出击判定只比较“守门员到达帧 ≤ 接球人到达帧”。
- 不考虑接球人的争顶属性。
- 传中拦截特质只扩大出击区域，不引入博弈。
- 传中很难形成真实威胁。

## 设计目标

1. **蓄力操作与传中结果强相关**  
   短按 = 近柱低弧快球，长按 = 远柱高弧慢球；蓄力档位有视觉和振动反馈，松手前能看到预期目标高亮。

2. **传中球稳定落到接球人附近**  
   落点基于接球人未来预测位置；接球人踢球帧即锁定，AI 不再打断；接球成功率可感知提升。

3. **接球过程流畅，动画高度匹配**  
   踢球帧按预测路径跑动；三档传中对应不同高度接球动画候选集。

4. **守门员出击有真实博弈感**  
   出击成功率由到位时差和双方争顶属性共同决定，传中有真实进球可能。

## 核心方案：球追人 Path A

踢球帧完成所有决策，球按预测落点飞行，接球人自然到位。轨迹固定后不再修正，满足帧同步刚性约束。

整体流程：

```text
玩家蓄力松手
→ M1 意图识别：档位 + 摇杆方向
→ M2 候选人筛选：动态归属度评分，输出 Top-3
→ M3 未来位置预测：输出 Top-1 到位位置、高度、置信度
→ M4 接球人锁定
→ M5 落点计算
→ M6 飞行风格映射
→ M7 球的飞行：踢球帧一次性固定完整轨迹
→ M8 接球人奔跑到位
→ M9 异常兜底
→ M10 守门员出击
```

## 模块拆解

### M1：玩家意图识别（P0）

- 按下传中键开始计时蓄力。
- 短按 `<0.3s` = 近柱。
- `0.3~0.7s` = 中路。
- `>0.7s` = 远柱。
- 读取摇杆方向，冲刺状态置零。
- 打包“传中意图”，踢球帧透传全链路。

### M2：候选人筛选（P0）

- 按蓄力档位计算每名球员动态归属度。
- 评分维度：归属度、摇杆偏向、可达性、越位软扣分、争顶能力。
- 输出 Top-3 候选。

### M3：未来位置预测（P0）

- 飞行时间 `<0.5s` 使用简单预测。
- 飞行时间 `≥0.5s` 使用增强预测，并加入防守修正。
- 用球员属性画可达圆，验证预测点可达性。
- 输出预测位置、预测到达高度、置信度。
- 低置信度激活 M9 兜底。

### M4：接球人锁定（P0）

- 踢球帧给 Top-1 候选打“传中锁定”标记。
- 锁定期间 AI 任务分配跳过此球员。
- Top-2/Top-3 保持跑位作为次选备用。
- 接到球、球被拦截或 M9 触发后解锁。

### M5：落点计算（P0）

- 落点直接取 M3 预测位置，废弃前柱-后柱线段投影。
- 飞行时间由接球人到位时间反算。
- 落点 1.5m 内有防守时，允许微偏，最大 1.5m。
- 超出 M6 飞行时间范围则触发 M9。

### M6：飞行风格映射（P1）

- 近柱档：低弧、快速、短滞空，飞行时间 `0.6~1.0s`。
- 中路档：标准弧、中速，飞行时间 `0.9~1.4s`。
- 远柱档：高弧、中低速、长滞空，飞行时间 `1.2~1.8s`。
- 飞行时间范围传给 M5，弧线参数传给 M7。

### M7：球的飞行（P0）

- 踢球帧一次性生成完整轨迹。
- 轨迹固定，飞行中不允许修正。
- 使用 55% 轨迹机制，微调球到接球人头部高度，依赖 M3 预测高度。

### M8：接球人奔跑到位（P0）

- 踢球帧立刻按 M3 预测路径跑动，替代每帧更新的 AI 接球规则。
- 路径偏差 `<30°`：融合修正。
- 路径偏差 `30°~90°`：转向动画。
- 路径偏差 `>90°`：触发 M9。
- 到落点前提前切接球准备动作，按 M3 预测高度决定头球、胸接或脚接。

### M9：异常兜底（P0）

四级递进：

1. 轻微修正：偏差 `<30°`，接球人微调路径。
2. 次选接手：偏差 `30°~90°`，解锁 Top-2 候选。
3. 落点微调：差一点点时微偏，最大 `0.5m`。
4. 传中失败：球落地，进入地面争抢。

### M10：守门员出击（P1）

- 计算接球人到位时间和守门员到位时间，得到时差。
- 时差大于阈值：直接出击。
- 时差接近 0：进入争顶属性博弈。
- 守门员明显慢：不出击。
- 球轨迹大幅变化时，守门员中止出击并回位。

### M11：玩家实时反馈（P1）

- 按下传中键立刻高亮 Top-1 候选，白色光圈。
- 蓄力进入新档位时，颜色变化并触发振动反馈。
- 近柱 = 黄，中路 = 橙，远柱 = 红。
- 松手后播放锁定动效。
- 球飞行中保持目标高亮，直到接球或落地。

## 玩家体验预期

- 底线短按传中：近柱球员高亮，低弧快球，接球人提前就位。
- 底线长按传中：远柱球员高亮，高弧慢球，滞空感明显。
- 传中球无人接：接球人提前预判跑位，兜底时有次选接手。
- 传中后射门：争顶成功后可顺畅衔接射门输入，减少停顿。
- 守门员出击：从“几乎必胜”变成“时差 + 属性”的博弈。

受益群体：

- **新手玩家**：蓄力反馈清晰，候选高亮让意图和结果对齐。
- **高手玩家**：可通过蓄力精确控制近、中、远三档落点。
- **防守玩家**：守门员出击不再无脑必胜，防守更真实。
- **竞技玩家**：传中从运气操作变为可控战术选择。

## 前置依赖与实施顺序

1. M1 传中意图结构必须最先完成，是所有模块的基础数据。
2. M2 候选人筛选依赖 M1。
3. M3 未来位置预测依赖 M2。
4. M5 落点计算依赖 M3 和 M6。
5. M8 接球人跑动依赖 M4。
6. M10 守门员出击可在主链路稳定后迭代。
7. M11 玩家反馈可与主链路并行，但不应阻塞 P0 逻辑。
