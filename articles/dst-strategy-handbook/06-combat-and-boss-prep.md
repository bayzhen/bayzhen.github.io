## 结论速查

DST 战斗最重要的不是勇，而是“穿护甲、带回血、知道什么时候撤”。新手每次开打前先检查四件事：护甲、武器、回血、光源。

| 战斗等级 | 最低准备 |
| --- | --- |
| 蜘蛛/小怪 | 木甲或头盔、长矛、少量回血 |
| 猎狗波 | 护甲、武器、开阔地、可借力的牛/猪/陷阱 |
| 季节 Boss | 多套护甲、足够回血、场地、队伍分工 |
| 遗迹战斗 | 照明、护甲、回血、撤退路线、背包管理 |

## 什么时候做

第一次主动清怪前就做护甲。Boss 战则必须提前一个阶段准备，听到提示再做装备通常太晚。

## 优先级清单

| 优先级 | 内容 |
| --- | --- |
| 必须 | 至少一件可用护甲 |
| 必须 | 可持续武器，不要只带一把快坏的 |
| 必须 | 战斗回血，和日常食物分开 |
| 必须 | 夜战光源或撤退路线 |
| 高 | 场地清理，避免卡树、卡墙、引到基地 |
| 高 | 队伍复活和捡尸方案 |

## 操作步骤

1. 小怪练习节奏：打几下、退一步、看攻击前摇，不要无脑站撸。
2. 战斗前把背包整理出空格，掉落物和备用装备才拿得下。
3. Boss 不要引进基地，尤其不要在核心仓库旁边打。
4. 队伍战斗时，非战斗角色也要做事：补护甲、递食物、处理小怪、准备复活。
5. 打不过就撤。存活和保装备比硬拼更重要。

## 常见错误

| 错误 | 后果 | 改法 |
| --- | --- | --- |
| 裸装试探 Boss | 一击后进入死亡螺旋 | 先穿护甲 |
| 回血全在基地 | 打架时用不上 | 随身带战斗回血 |
| 在基地开 Boss | 建筑和仓库损失巨大 | 拉到预设场地 |
| 只看输出角色 | 后勤断补给 | 战斗是团队流程 |
