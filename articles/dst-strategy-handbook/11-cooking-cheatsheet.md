## 什么时候做

第 8-15 天就应该有锅。只靠采集可以撑开局，但不能支撑冬季、战斗和多人队伍。

## 5 条规则

| 记住 | 决策 |
| --- | --- |
| 锅要 4 格 | 少一格不能做饭 |
| 先放主料 | 肉、蛋、菜、鱼、蜂蜜先确定 |
| 再放填充 | 用便宜、快坏、不抢配方的材料补满 |
| 怪物肉限量 | 默认每锅最多 1 个 |
| 树枝慎用 | 不是通用填充，只在需要时放 |

## 肉、怪物肉和小肉

先把“肉类”和“怪物”分开理解。怪物肉也算肉，所以它能满足很多“需要肉”的配方；但它额外带怪物标签，吃下去和放进锅里都有风险。

| 食材 | 怎么想 |
| --- | --- |
| 大肉 | 高价值主料，留给锅或晒肉 |
| 小肉 | 低肉值，适合肉丸、饺子、培根煎蛋 |
| 怪物肉 | 廉价肉源，但带怪物标签；每锅默认 1 个 |
| 蛋 | 鸟笼把肉转成蛋，用来做饺子/培根煎蛋 |

实战规则：普通肉是“高价值主料”，怪物肉是“需要转化的廉价肉”。有鸟笼后，多余怪物肉优先换蛋；没有鸟笼时，每锅最多按 1 个怪物肉规划。

## 什么是填充物

填充物不是游戏里的正式分类，而是做饭时的角色：目标配方只需要 1-3 个关键食材，剩下的格子要用不会抢配方、不会触发禁忌的材料补满。

| 填充物 | 判断 |
| --- | --- |
| 浆果 | 早期最常用，快坏先用 |
| 冰 | 冬季好用，适合补格 |
| 蔬菜 | 能补格；做饺子时是主料 |
| 蘑菇 | 能补格；别盲目生吃 |
| 树枝 | 特定配方用，不是万能填充 |
| 怪物肉 | 可少量用，默认每锅 1 个 |

判断填充物的顺序：先确定目标料理的关键食材，再排除禁忌食材，最后用便宜、快腐、库存多的材料补满 4 格。

## 常用决策表

| 手里有 | 先做 |
| --- | --- |
| 1 肉 + 3 填充 | 肉丸 |
| 肉 + 蛋 + 菜 | 饺子 |
| 鱼 + 树枝 | 鱼排 |
| 蜂蜜 3 + 树枝 | 太妃糖 |
| 蜂蜜 + 肉 | 蜂蜜料理 |
| 很多怪物肉 | 换蛋 |
| 三级蜘蛛巢 | 打掉拿蜘蛛卵，搬到家外 |

这里故意不把所有精确数值列满。游戏中真正要快，是先知道“这类材料该往哪个方向做”，精确食谱用完整数据库核对。

## 稳定怪物肉：搬蜘蛛巢

想长期做肉丸、饺子和换蛋，蜘蛛巢是最早能建立的稳定怪物肉来源。

<div class="quick-ref">
  <section>
    <h3>搬巢步骤</h3>
    <dl>
      <dt>找目标</dt>
      <dd>找三级蜘蛛巢。</dd>
      <dt>先清怪</dt>
      <dd>用陷阱或逐批引出蜘蛛。</dd>
      <dt>打掉巢</dt>
      <dd>三级巢会掉蜘蛛卵。</dd>
      <dt>带回家外</dt>
      <dd>种在基地外一段距离。</dd>
      <dt>等成长</dt>
      <dd>一级巢会慢慢长回高级。</dd>
    </dl>
  </section>

  <section>
    <h3>摆放原则</h3>
    <dl>
      <dt>不要贴家</dt>
      <dd>离锅、箱子、火源远一点。</dd>
      <dt>不要挡路</dt>
      <dd>别放主路和牛群边上。</dd>
      <dt>旁边留空</dt>
      <dd>方便放陷阱、拉怪、捡掉落。</dd>
      <dt>新手数量</dt>
      <dd>先 1-2 个巢，别贪多。</dd>
      <dt>夜晚小心</dt>
      <dd>黄昏和夜晚蜘蛛会外出。</dd>
    </dl>
  </section>
</div>

产出怎么用：怪物肉每锅少量入锅，更多喂鸟换蛋；蜘蛛腺留给回血；蛛丝做捕虫网、鸟笼、帐篷等关键物品。

## 太妃糖

太妃糖就记一行：蜂蜜 3 + 树枝 1。

它是理智补给，不是日常饭。蜂箱成型后很好用；早期蜂蜜少时，不要为了回一点理智把蜂蜜全做掉。

## 操作步骤

1. 先建锅，再建冰箱。锅解决效率，冰箱解决时间。
2. 每次做饭先问：这顿饭是给日常吃，还是留给战斗回血？
3. 战斗回血单独放箱子或背包，不要日常饿了顺手吃光。
4. 先放关键食材，再放填充物；不确定时先查目标料理的禁忌食材。
5. 怪物肉优先转化，不要当普通肉大量直吃。
6. 多人局指定一个“做饭箱”，把肉、蛋、蔬菜、蜂蜜、鱼、填充物分区放。

## 常见错误

| 错误 | 改法 |
| --- | --- |
| 生吃所有食材 | 先入锅 |
| 怪物肉乱塞 | 每锅默认 1 个 |
| 树枝乱放 | 只按配方放 |
| 回血料理当饭 | 单独留战斗库存 |
| 只背食谱 | 按“饿/回血/理智”分类 |
