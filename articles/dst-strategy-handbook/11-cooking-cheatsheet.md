## 什么时候做

第 12 天前建锅。第 15 天仍没有锅，就停止探图；先补 3 切石、6 木炭、6 树枝。

## 5 条规则

| 记住 | 决策 |
| --- | --- |
| 锅要 4 格 | 少一格不能做饭 |
| 先放主料 | 肉、蛋、菜、鱼、蜂蜜先确定 |
| 再放填充 | 用浆果、冰、蔬菜、蘑菇补满 |
| 怪物肉限量 | 默认每锅最多 1 个 |
| 树枝慎用 | 鱼排和太妃糖需要；肉丸不放 |

## 肉、怪物肉和小肉

肉类分两层：普通肉只提供肉标签；怪物肉同时提供肉标签和怪物标签。怪物标签超过 1 个时，按失败处理。

| 食材 | 决策 |
| --- | --- |
| 大肉 | 高价值主料，留给锅或晒肉 |
| 小肉 | 低肉值，用于肉丸、饺子、培根煎蛋 |
| 怪物肉 | 廉价肉源，但带怪物标签；每锅默认 1 个 |
| 蛋 | 鸟笼把肉转成蛋，用来做饺子/培根煎蛋 |

实战规则：普通肉留给高价值料理；怪物肉每锅最多 1 个。有鸟笼后，多余怪物肉全部喂鸟换蛋。

## 什么是填充物

填充物不是游戏里的正式分类，而是做饭时的角色：目标配方只需要 1-3 个关键食材，剩下的格子要用不会抢配方、不会触发禁忌的材料补满。

| 填充物 | 判断 |
| --- | --- |
| 浆果 | 早期最常用，快坏先用 |
| 冰 | 冬季补格；肉丸可用 |
| 蔬菜 | 能补格；做饺子时是主料 |
| 蘑菇 | 能补格；别盲目生吃 |
| 树枝 | 特定配方用，不是万能填充 |
| 怪物肉 | 每锅最多 1 个 |

填充顺序固定为：先放目标料理主料，再用浆果/冰/蔬菜/蘑菇补满 4 格；树枝只在鱼排、太妃糖等明确配方里放。

## 常用决策表

| 手里有 | 先做 |
| --- | --- |
| 1 肉 + 3 填充 | 肉丸 |
| 肉 + 蛋 + 菜 | 饺子 |
| 鱼 + 树枝 | 鱼排 |
| 蜂蜜 3 + 树枝 | 太妃糖 |
| 蜂蜜 + 肉 | 蜂蜜料理 |
| 很多怪物肉 | 换蛋 |
| 三级蜘蛛巢 | 打掉拿蜘蛛卵，搬到家外 |

这张表用于实战决策。没有查表时间时，按表做；要做冷门料理时再查完整数据库。

## 稳定怪物肉：搬蜘蛛巢

长期肉丸、饺子和换蛋依赖蜘蛛巢。第 20 天前搬 1 个巢，第 35 天前扩到 2 个巢。

<div class="quick-ref">
  <section>
    <h3>搬巢步骤</h3>
    <dl>
      <dt>找目标</dt>
      <dd>找三级蜘蛛巢。</dd>
      <dt>先清怪</dt>
      <dd>用陷阱或逐批引出蜘蛛。</dd>
      <dt>打掉巢</dt>
      <dd>三级巢会掉蜘蛛卵。</dd>
      <dt>带回家外</dt>
      <dd>种在基地外一段距离。</dd>
      <dt>等成长</dt>
      <dd>一级巢会慢慢长回高级。</dd>
    </dl>
  </section>

  <section>
    <h3>摆放原则</h3>
    <dl>
      <dt>不要贴家</dt>
      <dd>离锅、箱子、火源远一点。</dd>
      <dt>不要挡路</dt>
      <dd>别放主路和牛群边上。</dd>
      <dt>旁边留空</dt>
      <dd>方便放陷阱、拉怪、捡掉落。</dd>
      <dt>新手数量</dt>
      <dd>第 20 天 1 个，第 35 天 2 个。</dd>
      <dt>夜晚小心</dt>
      <dd>黄昏和夜晚蜘蛛会外出。</dd>
    </dl>
  </section>

产出分配：怪物肉每锅 1 个或喂鸟换蛋；蜘蛛腺放战斗箱；蛛丝优先做捕虫网、鸟笼、帐篷。

## 太妃糖

太妃糖就记一行：蜂蜜 3 + 树枝 1。

太妃糖用于理智补给，不用于日常饱食。第 35 天前蜂蜜少，蜂蜜优先留给蜂箱扩张和关键料理；第 35 天后有 2 个蜂箱再批量做太妃糖。

## 操作步骤

| 步骤 | 执行标准 |
| --- | --- |
| 建锅 | 第 12 天前完成；多人局第 20 天做第 2 个锅 |
| 建冰箱 | 齿轮到手后立刻做；放在锅旁 |
| 分类 | 日常食物和回血料理分箱；回血箱常备 4 份 |
| 做饭 | 主料先放，填充后放；怪物肉每锅最多 1 个 |
| 转化 | 怪物肉多于 4 个时，优先喂鸟换蛋 |
| 多人局 | 肉、蛋、蔬菜、蜂蜜、鱼、填充物各固定位置 |

## 常见错误

| 错误 | 改法 |
| --- | --- |
| 生吃所有食材 | 先入锅 |
| 怪物肉乱塞 | 每锅默认 1 个 |
| 树枝乱放 | 只按配方放 |
| 回血料理当饭 | 单独留战斗库存 |
| 只背食谱 | 按“饿/回血/理智”分类 |
