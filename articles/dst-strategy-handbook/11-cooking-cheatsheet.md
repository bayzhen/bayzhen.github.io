## 结论速查

不要先背全食谱。先判断你要解决什么问题：饥饿、回血、理智、保鲜，还是处理怪物肉。

| 需求 | 新手优先选择 | 原因 |
| --- | --- | --- |
| 填饥饿 | 肉丸 | 配方宽松，适合早期 |
| 回血 | 饺子、鱼排等回血料理 | 战斗前后最实用 |
| 回理智 | 太妃糖、熟仙人掌等 | 比硬扛暗影怪安全 |
| 保鲜 | 冰箱、晾肉、做成料理 | 让食材变成可计划库存 |
| 处理怪物肉 | 少量入锅或换蛋 | 直接吃代价高 |

## 什么时候做

第 8-15 天就应该有锅。只靠采集可以撑开局，但不能支撑冬季、战斗和多人队伍。

## 食材规则

| 规则 | 含义 |
| --- | --- |
| 炊具锅每次 4 格 | 少一格不能做，多数料理按食材标签判断 |
| 怪物肉要克制使用 | 很多料理可以用 1 个怪物肉，但堆太多会出坏结果 |
| 填充物很重要 | 浆果、冰、蔬菜等常用于补格子 |
| 不可食用物要小心 | 树枝等会改变配方结果 |
| 食谱优先级存在 | 同一组材料可能命中不同料理，精确配方要查表 |

## 常用决策表

| 你手里有什么 | 先考虑 |
| --- | --- |
| 1 个肉 + 3 个填充 | 肉丸，解决饥饿 |
| 肉 + 蛋 + 蔬菜 + 填充 | 饺子，偏回血 |
| 鱼 + 树枝 + 填充 | 鱼排类，偏回血 |
| 蜂蜜 + 肉类 | 蜂蜜料理，适合中期循环 |
| 大量怪物肉 | 鸟笼换蛋，或少量分散入锅 |

这里故意不把所有精确数值列满。游戏中真正要快，是先知道“这类材料该往哪个方向做”，精确食谱用完整数据库核对。

## 操作步骤

1. 先建锅，再建冰箱。锅解决效率，冰箱解决时间。
2. 每次做饭先问：这顿饭是给日常吃，还是留给战斗回血？
3. 战斗回血单独放箱子或背包，不要日常饿了顺手吃光。
4. 怪物肉优先转化，不要当普通肉大量直吃。
5. 多人局指定一个“做饭箱”，把肉、蛋、蔬菜、填充物分区放。

## 常见错误

| 错误 | 后果 | 改法 |
| --- | --- | --- |
| 生吃所有食材 | 浪费恢复量和保鲜价值 | 先入锅 |
| 怪物肉乱塞 | 出错料理或惩罚 | 每次少量、查规则 |
| 回血料理当饭吃 | 打架时没急救 | 日常食物和回血食物分开 |
| 背全食谱但不会判断 | 游戏中还是手忙脚乱 | 按需求分类记 |
