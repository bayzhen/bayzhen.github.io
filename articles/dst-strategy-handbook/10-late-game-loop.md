## 结论速查

后期从第 70 天开始。目标不是“继续活着”，而是按季维护库存、按批次推进 Boss 和遗迹、把远资源点做成前哨。

| 后期目标 | 完成标准 |
| --- | --- |
| 洞穴/遗迹推进 | 每次下洞有固定补给箱和撤退线 |
| Boss 循环 | 每个 Boss 有独立战场和战前箱 |
| 基地分区 | 食物、战斗、材料、稀有品、季节物资分箱 |
| 前哨和道路 | 洞口、沙漠、沼泽、猪王至少 2 处有前哨 |
| 资源半自动化 | 蜘蛛巢、蜂箱、农场、晾肉架形成固定循环 |
| 装饰和大型工程 | 库存线达标后再做 |

## 什么时候做

满足 4 条后进入后期推进：锅/冰箱正常、每季库存线达标、战斗箱常备、至少 1 个复活方案可用。缺任一条，继续补生存系统。

## 优先级清单

| 优先级 | 动作 |
| --- | --- |
| 必须 | 草 80、树枝 80、木头 80、石头 80、金子 40 |
| 必须 | 战斗箱：护甲 4、武器 4、回血 8、光源 4 |
| 高 | 每个 Boss 独立战场和战前箱 |
| 高 | 洞穴/遗迹按 1 次侦察 + 1 次采集 + 1 次战斗推进 |
| 中 | 蜘蛛巢 2、蜂箱 4、晾肉架 8、农田专属种子循环 |
| 低 | 美化基地和大型工程 |

## 操作步骤

| 周期 | 固定动作 |
| --- | --- |
| 每 5 天 | 检查草、树枝、木头、石头、金子、回血库存线 |
| 每季开始 | 检查季节装备、防火/避雷/保暖/降温 |
| 每次 Boss 前 | 战前箱补满，确认外场，确认复活方案 |
| 每次遗迹前 | 单独备 2 光源、2 护甲、4 回血、6 空格 |
| 每季结束 | 清理危险生物、废弃物、错误摆放的可燃物 |

## 常见错误

| 错误 | 后果 | 改法 |
| --- | --- | --- |
| 后期只装饰不维护 | 下一次危机突然断档 | 先库存线，后美化 |
| Boss 掉落无规划 | 打了也不知道用来做什么 | 先定目标装备/建筑 |
| 所有人都分散单干 | 资源重复消耗，救援困难 | 设公共目标 |
| 不愿重置但锅/冰箱/科技/资源箱全毁 | 长期维护成本过高 | 入冬或入夏时开新世界；秋春时救世界 |
