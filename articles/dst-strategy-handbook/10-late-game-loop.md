## 结论速查

后期不是“不会死了就结束”，而是把世界变成可持续系统：资源可再生、Boss 可循环、路线清晰、基地可维护。

| 后期目标 | 意义 |
| --- | --- |
| 完成洞穴/遗迹推进 | 解锁更高层科技和装备 |
| 建立 Boss 循环 | 稳定获取关键掉落 |
| 优化基地分区 | 降低维护成本和事故损失 |
| 建前哨和道路 | 缩短远行时间 |
| 资源自动/半自动化 | 减少重复劳动 |
| 挑战内容和装饰 | 给长期世界目标 |

## 什么时候做

第一个完整年循环后，如果食物、季节、战斗和复活都稳定，就可以把目标从“生存”切到“推进”。

## 优先级清单

| 优先级 | 动作 |
| --- | --- |
| 必须 | 维护草、树枝、木头、石头、金子库存 |
| 必须 | 保持战斗补给可用 |
| 高 | 规划 Boss 时间表和战场 |
| 高 | 继续推进洞穴和遗迹 |
| 中 | 美化基地和建设大型工程 |
| 中 | 设计专门农场和资源区 |

## 操作步骤

1. 为每个季节建立固定例行任务：补资源、处理 Boss、检查基地风险。
2. Boss 战场独立于主基地，战前箱固定放护甲、武器、回血、光源。
3. 遗迹推进按批次进行，不要每次都从基地临时拼装备。
4. 把远资源点变成前哨：箱子、火坑、备用灯、少量补给。
5. 长期世界定期清理无用物品和危险生物，减少服务器和玩家负担。

## 常见错误

| 错误 | 后果 | 改法 |
| --- | --- | --- |
| 后期只装饰不维护 | 下一次危机突然断档 | 先库存线，后美化 |
| Boss 掉落无规划 | 打了也不知道用来做什么 | 先定目标装备/建筑 |
| 所有人都分散单干 | 资源重复消耗，救援困难 | 设公共目标 |
| 不愿重置但世界已混乱 | 长期维护成本过高 | 判断是否新世界更有效 |
