## 结论速查

好基地不等于离所有东西都近，而是让“高频资源近、危险资源可控、远程资源有路线”。

| 基地条件 | 评价 |
| --- | --- |
| 靠近道路/虫洞 | 强，节省大量通勤时间 |
| 离草、树枝、木头近 | 强，日常消耗稳定 |
| 离牛群太近 | 中等，方便但发情期危险 |
| 建在沼泽里面 | 高风险，新手不建议 |
| 建在纯石地中心 | 不适合主基地，适合矿区前哨 |
| 贴着危险巢穴 | 不要，除非你明确做农场 |

## 什么时候做

第 5-8 天建主基地最舒服。太早会选址盲目，太晚会压缩入冬准备时间。

## 优先级清单

| 阶段 | 建筑/区域 | 目的 |
| --- | --- | --- |
| 初期 | 火坑、科学机器、箱子 | 稳定夜晚和解锁基础科技 |
| 初期 | 炊具锅、冰箱 | 食物系统成型 |
| 初期 | 避雷针 | 防止春季和随机雷击烧家 |
| 中期 | 炼金引擎、鸟笼、晾肉架 | 进阶科技和食物循环 |
| 中期 | 草/树枝/浆果移植区 | 减少日常采集时间 |
| 中期 | 战斗补给箱 | 护甲、武器、回血、照明集中管理 |

## 操作步骤

1. 先放火坑和 2-3 个箱子，不要马上铺满结构。
2. 科技建筑放在核心区边缘，箱子按用途分区：食物、战斗、材料、宝石/稀有品。
3. 可燃资源不要密集堆在火源旁。树、草、树枝、浆果分组种植，中间留隔离带。
4. 洞口、沙漠、沼泽、猪王太远时，建小前哨：火坑、箱子、少量食物和护甲。
5. 每次远行前从战斗补给箱拿固定套装，回来立刻补齐。

## 常见错误

| 错误 | 后果 | 改法 |
| --- | --- | --- |
| 所有资源贴在一起 | 一次火灾毁全家 | 分区、留空、做避雷和灭火 |
| 主基地离一切都很远 | 通勤吃掉大部分白天 | 用道路/虫洞/前哨补救 |
| 箱子无分类 | 打 Boss 前找不到护甲回血 | 每类物品固定箱子 |
| 把危险农场建在核心区 | 狗、蜘蛛、触手进家 | 农场和基地保持距离 |
