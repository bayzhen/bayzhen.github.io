## 按天数查

默认世界是：秋 1-20 天、冬 21-35 天、春 36-55 天、夏 56-70 天，然后循环。服务器改过季节长度时，按实际季节图标套用对应清单。

| 天数 | 应该做什么 | 不该做什么 |
| --- | --- | --- |
| 1-3 | 沿路探图，捡草/树枝/燧石，做火把、斧头、镐子 | 原地砍树造大基地 |
| 4-7 | 找金子，解锁背包/铲子/长矛/木甲，判断基地位置 | 把所有资源移植回家 |
| 8-15 | 建锅、冰箱、6 箱、避雷雏形，建立 1 肉源 + 1 填充物来源 | 只靠捡浆果过日子 |
| 16-20 | 木头/草/树枝各 40，热能石，冬帽/牛帽，2 护甲，4 回血 | 远行不带保暖和回程计划 |
| 21-35 | 每次出门带热源、光源、2 食物、1 护甲，准备春季避雷和雨具 | 长时间无准备探远图 |
| 36-55 | 核心区避雷，雨具，灭火器或洞穴避暑方案 | 基地无避雷、资源堆太密 |
| 56-70 | 核心区停止点火打架，地表只做短途补给 | 在核心基地旁打架或点火 |
| 70+ | 进入循环：Boss、洞穴遗迹、资源维护、长期目标 | 只装饰不补库存 |
