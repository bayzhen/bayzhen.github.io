## 这套手册怎么用

这不是剧情介绍，也不是全物品百科。它的目标是：你在开局前、死亡后、入冬前、打 Boss 前，能快速找到下一步应该做什么。

## 快速查找

| 问题 | 直接结论 |
| --- | --- |
| 开局先做什么 | 沿路探图，捡草/树枝/燧石/浆果，做斧镐火把，不急着定居 |
| 什么时候定基地 | 通常第 5-8 天，先知道牛群、猪王、沙漠、沼泽、洞口的大致位置 |
| 入冬前必须有什么 | 保暖、稳定食物、木头草树枝、护甲武器、避雷/灭火规划的雏形 |
| 战斗前最低配置 | 至少一件护甲、一把武器、回血食物、光源和撤退路线 |
| 下洞穴前带什么 | 灯、备用燃料、护甲、回血、锤/镐、少量食物，先侦察不贪 |
| 基地最怕什么 | 火、季节危机、资源堆太密、把危险生物引到核心区 |
