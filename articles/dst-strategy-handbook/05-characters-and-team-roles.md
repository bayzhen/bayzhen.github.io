## 结论速查

角色选择先看队伍需要，不要只看单人强度。多人局最缺的通常不是输出，而是稳定执行：探图、建家、做饭、打怪、补资源、救场。

| 队伍职责 | 主要工作 |
| --- | --- |
| 探图手 | 找资源点、虫洞、洞口、猪王、沙漠、沼泽 |
| 后勤手 | 建家、分类箱子、补草木树枝、维护基地 |
| 厨师/农夫 | 食材循环、料理、回血和理智补给 |
| 战斗手 | 清怪、刷材料、准备 Boss 战 |
| 洞穴手 | 下洞侦察、拿荧光果、规划遗迹路线 |
| 救场手 | 复活、补给、危机处理、捡尸 |

## 什么时候做

开局前就决定粗分工，但不要把人锁死。第 10 天后根据地图和季节调整。

## 优先级清单

| 玩家水平 | 推荐思路 |
| --- | --- |
| 新手 | 选机制直观、缺点少、不会拖累队伍的角色 |
| 熟手 | 选能放大队伍效率的角色 |
| 战斗玩家 | 负责护甲武器和 Boss 准备，不要只等开打 |
| 后勤玩家 | 建立食物、材料、复活和危机系统 |

## 操作步骤

1. 开局 5 分钟内说清楚谁探哪边，避免所有人沿同一路线捡同一批资源。
2. 每个人回家时带回一种紧缺资源，而不是空手回来。
3. 基地箱子命名或按位置固定，不要把团队物资放进个人背包消失。
4. 打 Boss 前指定指挥：谁拉仇恨、谁补给、谁救人、谁处理小怪。
5. 角色能力变化频繁，具体技能和数值开局前再查当前版本。

## 常见错误

| 错误 | 后果 | 改法 |
| --- | --- | --- |
| 每个人都想当输出 | 家没人维护，食物断档 | 明确后勤和补给 |
| 新手选高惩罚角色 | 自己压力大，队友救火 | 先选直观角色 |
| 物资私有化 | 团队关键时刻缺护甲回血 | 公共箱和战斗箱 |
| 不沟通 Boss 计划 | 团灭后没人知道东西在哪 | 开打前分工 |
