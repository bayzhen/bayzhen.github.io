## 结论速查

资源循环的目标不是“仓库塞满”，而是让关键消耗品能重复生产：食物、护甲、武器、回血、照明、燃料。

| 循环 | 关键点 |
| --- | --- |
| 炊具锅 | 把零散食材变成稳定料理 |
| 鸟笼 | 扩展蛋类和食谱空间 |
| 农场 | 稳定蔬果，但需要管理压力和营养 |
| 蜘蛛/猪/兔/鱼 | 稳定肉、怪物肉、蜘蛛腺等 |
| 蜂箱/花/晾肉架 | 蜂蜜、太妃糖、蜂蜜料理和保鲜 |
| 草树枝木头 | 一切工具、火源和建筑的底层消耗 |

## 什么时候做

第一个冬天前至少要有炊具锅和初步肉/蔬菜来源。农场可以中期完善，不必第一周就追求巨大化作物。

## 优先级清单

| 阶段 | 目标 |
| --- | --- |
| 初期 | 炊具锅、冰箱、基础肉源 |
| 入冬前 | 可存储食物、晾肉架、稳定燃料 |
| 中期 | 农田规划、鸟笼、蜂箱、花田或其他回血循环 |
| 后期 | 分类库存、批量生产、专门农场 |

## 蜂箱和花怎么做

蜂箱不是只放箱子就完事。它需要蜜蜂、蜂巢和花，稳定后能提供蜂蜜，用来做太妃糖和蜂蜜料理。

| 问题 | 速查 |
| --- | --- |
| 蜂箱怎么造 | 木板 2 + 蜂巢 1 + 蜜蜂 4 |
| 蜜蜂怎么来 | 捕虫网抓普通蜜蜂 |
| 蜂巢怎么来 | 打掉野外蜂窝获得 |
| 花怎么种 | 捕虫网抓蝴蝶，把活蝴蝶种到地上 |
| 花要多少 | 每个蜂箱旁边至少 6 朵更稳 |
| 放在哪里 | 基地外侧，离花近，离常走动线远 |
| 蜂蜜做什么 | 太妃糖、蜜汁火腿、蜜汁卤肉等 |

采蜜时，箱内蜜蜂会出来追你。新手做法是蜂箱区留一条直路，采完直接跑开；不要把蜂箱贴着锅、冰箱、箱子和复活区。

## 操作步骤

1. 先解决“每天吃什么”，再解决“怎么高效量产”。
2. 农场不要只看种下去，还要关注水分、营养、杂草和作物组合。
3. 找到三级蜘蛛巢后，清怪打巢拿蜘蛛卵，把巢搬到基地外，作为稳定怪物肉来源。
4. 肉源要和安全距离绑定，蜘蛛巢、猪房、兔场不要贴核心区。
5. 蜂箱区单独放：蜂箱、花、逃跑路线，不要混进核心基地。
6. 常用料理的材料放在同一片区域或相邻箱子，减少做饭时间。
7. 设定库存下限：草、树枝、木头、石头、金子、护甲、回血一低于线就补。

## 常见错误

| 错误 | 后果 | 改法 |
| --- | --- | --- |
| 只种田不做锅 | 食物价值低 | 锅是食物系统核心 |
| 只囤食物不囤材料 | 一波战斗后护甲断档 | 食物和战斗物资一起循环 |
| 蜘蛛巢搬太近 | 回家、做饭、捡箱子都被骚扰 | 放基地外，留陷阱区 |
| 看到三级巢直接烧 | 拿不到蜘蛛卵，失去搬巢机会 | 清怪后打掉巢 |
| 蜂箱贴核心区 | 采蜜被追，春天更乱 | 蜂箱区外置 |
| 只造蜂箱不种花 | 蜂蜜产出慢或停 | 抓蝴蝶种花 |
| 农场贴着基地核心 | 杂乱、火灾和动线问题 | 单独农区 |
| 不设库存线 | 总在缺东西时才发现 | 用箱子容量做下限提醒 |
