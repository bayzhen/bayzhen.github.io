## 结论速查

选角按队伍缺口决定。新手默认选“饮食正常、战斗规则正常、后勤压力低”的角色；特殊机制角色必须先读当前版本页面。

| 队伍缺口 | 选角规则 |
| --- | --- |
| 新手活下来 | 选默认饮食、默认理智、缺点少的角色 |
| 缺输出 | 选战斗角色，同时认领战斗箱 |
| 缺后勤 | 选资源、建造、烹饪、农场或支援角色，同时认领库存线 |
| 常团灭 | 选复活、治疗、控场或降操作压力的角色 |
| 想玩特殊机制 | 先查食物禁忌、理智规则、技能树、队伍负担 |

## 什么时候查角色细节

以下情况必须查当前版本；不查就不选：

| 情况 | 为什么 |
| --- | --- |
| 角色有技能树 | 技能路线改变职责和战斗方式 |
| 角色近期重做 | 旧攻略不作为依据 |
| 角色有食物/资源限制 | 影响做饭、回血、后勤 |
| 多人配合 | 角色收益必须对应队伍缺口 |
| 打 Boss 或下遗迹 | 特殊机制会改变装备和补给要求 |

## 队伍职责表

| 职责 | 交付物 | 常见误区 |
| --- | --- | --- |
| 探图 | 第 10 天前标 5 类资源点 | 背包满就回，不标信息 |
| 后勤 | 第 12 天前 6 箱分类、锅、冰箱 | 只装饰不维护 |
| 厨师/农夫 | 战斗回血 4、肉源 1、填充物来源 1 | 做饭没人知道放哪 |
| 战斗 | 战斗箱：护甲 2、武器 2、回血 4、光源 2 | 只输出不准备补给 |
| 洞穴 | 洞口标记、下洞补给、撤退线 | 贪资源不撤退 |
| 救场 | 备用护甲光源、复活方案、尸体路线 | 裸身冲尸体 |

## 技能树和 Insight

DST 的部分角色有技能树。Insight 是角色技能树相关的点数系统，会随角色生存天数积累，并且不同角色的技能选择会改变玩法重点。

| 技能树决策 | 执行规则 |
| --- | --- |
| 新手加点 | 先点能降低死亡、补资源、补食物的技能 |
| 多人加点 | 队伍缺什么点什么，不照抄单人输出路线 |
| 换角色/重置 | 操作前读当前角色页面 |
| 暗影/月亮路线 | 队伍进入后期推进后再选；生存未稳不点后期路线 |

## 特殊角色检查清单

| 检查项 | 必须确认 |
| --- | --- |
| 食物规则 | 能吃什么，不能吃什么，回血是否受限 |
| 专属物品 | 开局带什么，消耗什么，谁负责补材料 |
| 战斗方式 | 伤害、召唤物、形态、年龄、宠物如何影响 Boss |
| 基地职责 | 是否改变建造、修理、烹饪、种植、蜘蛛/鱼人生态 |
| 队友配合 | 需要队友提供什么资源或保护 |

## 常见错误

| 错误 | 后果 | 改法 |
| --- | --- | --- |
| 只看强度榜 | 不适合当前队伍 | 按职责选 |
| 不读角色缺点 | 食物/理智/战斗节奏崩 | 开局前查角色页 |
| 技能树照抄 | 队伍需求不匹配 | 按本局目标点 |
| 多人全选输出 | 家和食物没人管 | 至少有后勤职责 |
