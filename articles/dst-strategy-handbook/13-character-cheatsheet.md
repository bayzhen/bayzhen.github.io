## 结论速查

选角色先问“队伍缺什么”，再问“我想玩什么”。强角色没人会用，效果不如机制简单但执行稳定的角色。

| 你想解决的问题 | 角色选择思路 |
| --- | --- |
| 新手活下来 | 选机制直观、惩罚少、对队伍负担低的角色 |
| 队伍缺输出 | 选战斗向角色，但要能准备护甲回血 |
| 队伍缺后勤 | 选资源、建造、烹饪、农场或支援能力强的角色 |
| 队伍常团灭 | 选能支援、救场或降低操作压力的组合 |
| 想玩特殊机制 | 先读角色页，确认食物、理智、技能树和禁忌 |

## 什么时候查角色细节

这些情况必须查当前版本：

| 情况 | 为什么 |
| --- | --- |
| 角色有技能树 | 技能点和路线会改变玩法 |
| 角色近期重做 | 老攻略可能完全过时 |
| 角色有特殊食物/资源限制 | 会影响队伍后勤 |
| 多人配合 | 有些能力单人强，多人价值不同 |
| 打 Boss 或下遗迹 | 特殊机制会放大风险或收益 |

## 队伍职责表

| 职责 | 要做的事 | 常见误区 |
| --- | --- | --- |
| 探图 | 找资源点、虫洞、洞口、猪王、沙漠 | 一路捡到背包满就回，不标信息 |
| 后勤 | 建家、分类箱、补库存 | 只装饰不维护 |
| 厨师/农夫 | 食物、回血、作物、保鲜 | 做饭没人知道放哪 |
| 战斗 | 清怪、Boss、护甲武器 | 只输出不准备补给 |
| 洞穴 | 侦察、荧光果、遗迹路线 | 贪资源不撤退 |
| 救场 | 复活、捡尸、危机止损 | 裸身冲尸体 |

## 技能树和 Insight

DST 的部分角色有技能树。Insight 是角色技能树相关的点数系统，会随角色生存天数积累，并且不同角色的技能选择会改变玩法重点。

实战建议：

1. 新手不要一上来追“终极加点”，先选能解决当前问题的技能。
2. 多人局技能选择看队伍，不只看单人强度。
3. 换世界、换角色、重置技能前，先读当前角色页面。
4. 有暗影/月亮路线等后期选择时，先确认队伍进度再点。

## 特殊角色检查清单

| 检查项 | 例子 |
| --- | --- |
| 吃什么有惩罚或加成 | 有些角色不按普通食物逻辑玩 |
| 是否自带专属物品 | 打火机、书、工程、乐器、灵魂等 |
| 是否改变战斗方式 | 伤害、召唤物、形态、年龄、宠物 |
| 是否改变基地职责 | 建造、修理、烹饪、种植、蜘蛛/鱼人等生态 |
| 是否需要队友配合 | 支援角色和资源角色尤其明显 |

## 常见错误

| 错误 | 后果 | 改法 |
| --- | --- | --- |
| 只看强度榜 | 不适合当前队伍 | 按职责选 |
| 不读角色缺点 | 食物/理智/战斗节奏崩 | 开局前查角色页 |
| 技能树照抄 | 队伍需求不匹配 | 按本局目标点 |
| 多人全选输出 | 家和食物没人管 | 至少有后勤职责 |
