## 结论速查

种地不是开局必做，但它是中期稳定食物和特定料理的重要系统。新手先把锅、冰箱、肉源做好，再考虑农场。

| 你现在的状态 | 建议 |
| --- | --- |
| 第 1-7 天 | 不急着种地，先探图和建基础科技 |
| 第 8-20 天 | 可以小规模试种，别把全部资源押上 |
| 冬季 | 更依赖库存和肉源，农场不是救命按钮 |
| 春季 | 水分较好，但要处理雨、雷和混乱风险 |
| 夏季 | 注意过热、自燃和地表行动成本 |
| 中后期 | 值得做专门农区和作物循环 |

## 什么时候做

满足这些条件再认真种：

| 条件 | 为什么 |
| --- | --- |
| 基地已稳定 | 农场需要维护，不能替代基础生存 |
| 有锅和冰箱 | 作物价值主要通过料理放大 |
| 有时间管理 | 种地要看阶段、水分、营养、杂草 |
| 队伍有人愿意管 | 多人局没人管的农场会变成杂草区 |

## 压力来源怎么理解

DST 农场有“植物压力”概念。你不用一开始背全部细节，但要知道压力来自几个方向：

| 压力方向 | 实战理解 |
| --- | --- |
| 季节 | 作物有偏好季节，不合适会更难照顾 |
| 水分 | 太干会影响成长，雨季和浇水能帮忙 |
| 营养 | 土壤有不同营养，作物会消耗/产生营养 |
| 拥挤 | 同一块太密会出问题 |
| 杂草 | 杂草会抢空间和资源，要及时处理 |
| 照料 | 互动和照看能改善结果 |

## 低维护做法

| 做法 | 适合谁 |
| --- | --- |
| 小农区试种 | 新手，先理解系统 |
| 只种常用料理相关作物 | 不想管理复杂农场的玩家 |
| 春季集中扩张 | 有雨水帮助，但要防雷和混乱 |
| 专人负责农场 | 多人局最稳定 |
| 查表做作物组合 | 想追求巨型作物和高效率的玩家 |

## 操作步骤

1. 先做小，不要一口气铺巨大农田。
2. 把农场放在基地旁但不要贴核心仓库，留出防火和行走空间。
3. 每次收获后清杂草、看库存、决定是否继续种。
4. 种出来的东西优先服务料理目标：回血、饥饿、理智，而不是纯囤积。
5. 想追求巨大作物时再查完整组合表，不要靠猜。

## 常见错误

| 错误 | 后果 | 改法 |
| --- | --- | --- |
| 开局全力种地 | 探图和冬季准备落后 | 第 8 天后小规模开始 |
| 不会做饭却大量种菜 | 作物价值用不出来 | 先学锅 |
| 农场无人维护 | 杂草和压力堆积 | 指定负责人 |
| 只看产量不看季节 | 维护成本变高 | 按季节调整 |
