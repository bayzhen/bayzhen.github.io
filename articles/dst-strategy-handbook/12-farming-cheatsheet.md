## 结论速查

种地从第 20 天后开始认真做。第 20 天前只做试种；锅、冰箱、肉源没完成时，不投入农场。

| 你现在的状态 | 决策 |
| --- | --- |
| 第 1-7 天 | 不种地；探图和科技优先 |
| 第 8-20 天 | 最多 1 块农田试种 |
| 冬季 | 不把农场当救命粮；吃库存和肉源 |
| 春季 | 扩到 2 块农田，先插避雷针 |
| 夏季 | 地表农场停止扩建，优先洞穴/防火方案 |
| 第 35 天后 | 专属种子循环，按料理目标种 |

## 什么时候做

满足全部条件再扩农场：

| 条件 | 为什么 |
| --- | --- |
| 锅和冰箱已建 | 作物必须进料理链 |
| 肉源已建 | 农场不替代肉源 |
| 避雷覆盖农区 | 春季不烧农场 |
| 有鸟笼 | 作物能换专属种子 |
| 有负责人 | 多人局每天检查水、杂草、收获 |

## 压力来源怎么理解

DST 农场有“植物压力”概念。你不用一开始背全部细节，但要知道压力来自几个方向：

| 压力方向 | 实战理解 |
| --- | --- |
| 季节 | 作物有偏好季节；不当季就不追巨大 |
| 水分 | 太干会影响成长，雨季和浇水能帮忙 |
| 营养 | 土壤有不同营养，作物会消耗/产生营养 |
| 拥挤 | 同一块太密会出问题 |
| 同伴 | 同种作物少于 4 株会有压力 |
| 杂草 | 杂草会抢空间和资源，要及时处理 |
| 照料 | 互动和照看能改善结果 |

## 提高效率怎么做

手机上只记这个顺序：当季 -> 清杂草 -> 浇水 -> 单块不超过 10 株 -> 同种 4 株 -> 每阶段照料。

| 目标 | 做法 |
| --- | --- |
| 少维护 | 第 20-35 天只种 1-2 块地 |
| 保种子 | 用专属种子，成熟作物喂鸟换对应种子 |
| 减压力 | 每阶段浇水和照料，及时清杂草和农田碎屑 |
| 防拥挤 | 单块农田最多按 9-10 株规划 |
| 凑同伴 | 同种作物 4 株成组，别东一棵西一棵 |
| 追巨大 | 再查作物组合和营养表，不要靠猜 |

新手目标只有两个：收获后能返种，能给锅提供蔬菜和特定作物。巨大作物放到第 35 天后再追。

## 低维护做法

| 做法 | 执行标准 |
| --- | --- |
| 小农区试种 | 第 20 天前最多 1 块 |
| 常用料理种植 | 只种肉丸填充、饺子蔬菜、火龙果派作物 |
| 春季扩张 | 先插避雷针，再扩到 2 块 |
| 专人负责 | 多人局每天固定 1 人检查农区 |
| 查表组合 | 追巨大作物前先查季节和营养组合 |

## 操作步骤

| 步骤 | 执行标准 |
| --- | --- |
| 开地 | 第 20 天前 1 块，第 35 天前最多 2 块 |
| 位置 | 农区离核心箱区至少半屏，避雷针覆盖 |
| 清理 | 耕地机开地后先清农田碎屑，再补坑位 |
| 种子 | 随机种子只试种；有鸟笼后用作物换专属种子 |
| 成长检查 | 每阶段检查水、杂草、照料、密度、同伴 |
| 收获后 | 清杂草，作物入锅或喂鸟换种 |
| 料理目标 | 作物优先服务回血、饥饿、理智 |
| 巨大作物 | 先查组合表，再按表种 |

## 常见错误

| 错误 | 后果 | 改法 |
| --- | --- | --- |
| 开局全力种地 | 探图和冬季准备落后 | 第 8 天后小规模开始 |
| 不会做饭却扩农场 | 作物价值用不出来 | 先学锅 |
| 农场无人维护 | 杂草和压力堆积 | 指定负责人 |
| 只看产量不看季节 | 维护成本变高 | 按季节调整 |
| 单块地塞太满 | 拥挤压力变高 | 控制在 9-10 株 |
| 不做种子循环 | 好作物断种 | 作物喂鸟换专属种子 |
| 不清杂草 | 农区越来越难管 | 看见就铲 |
