## 结论速查

前 7 天不要急着造漂亮基地。你的目标是把地图骨架摸出来，确认资源区，建立临时补给点，并在入冬前留下足够时间。

| 时间 | 目标 | 不要做 |
| --- | --- | --- |
| 第 1-2 天 | 探路，捡草、树枝、燧石、浆果，做斧头/镐子/火把 | 原地砍一整片森林 |
| 第 3-4 天 | 找金子，做科学机器，解锁背包、铲子、长矛、木甲 | 过早移植全部浆果和草 |
| 第 5-7 天 | 判断基地候选点，做临时箱子和火坑，准备食物来源 | 把家建在危险生物脸上 |

## 什么时候定基地

建议先探到这些信息再定：

| 信息 | 为什么重要 |
| --- | --- |
| 牛群/草原 | 粪便、毛、肉、冬帽路线，早期安全感强 |
| 猪王/猪村 | 换金子、猪皮、月圆风险 |
| 沙漠 | 仙人掌、风滚草、夏季相关内容 |
| 沼泽 | 芦苇、触手、鱼人，收益高但危险 |
| 洞口 | 下洞补光、荧光果、遗迹路线 |
| 虫洞 | 决定基地到远资源点的动线 |

如果第 7 天还没找到完美位置，先建“能活”的基地，不要为了完美选址拖到冬天。

## 优先级清单

| 优先级 | 物品/行为 | 原因 |
| --- | --- | --- |
| 必须 | 火把 | 夜晚没有光就是死亡风险 |
| 必须 | 斧头、镐子 | 木头、石头、金子是科技入口 |
| 必须 | 背包 | 探图效率直接上升 |
| 高 | 铲子 | 移植资源，但不要把全图挖空 |
| 高 | 长矛和木甲 | 第一次被狗追或打怪时不至于裸奔 |
| 中 | 捕虫网、鸟笼准备 | 后续蛋、填充物和食物循环更稳 |

## 操作步骤

1. 白天沿道路和地形边缘探图。道路加速能节省大量时间。
2. 黄昏继续探，但手上保持火把材料。
3. 夜晚如果没事做，就砍树、烧远离基地的孤立树拿木炭，或整理背包。
4. 找到金子后立刻做科学机器，解锁常用原型，然后可以锤掉或留作临时点。
5. 第 5 天开始缩小基地候选，不要继续无目的绕圈。

## 常见错误

| 错误 | 后果 | 改法 |
| --- | --- | --- |
| 第一天就定居 | 后面发现远离关键资源 | 先探图再定居 |
| 夜晚只站着等 | 浪费 1/3 时间 | 夜晚砍树、烤食物、整理 |
| 看到怪就打 | 护甲和回血不足会滚雪球死亡 | 先做护甲，再学习攻击节奏 |
| 食物全吃掉 | 没有储备，入冬前断粮 | 早期吃快腐，耐放食物留后面 |
