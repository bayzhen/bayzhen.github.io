## 结论速查

第一次下洞不要想着“清遗迹”。目标是侦察：找光源、找路线、拿少量关键资源，然后安全回来。

| 阶段 | 目标 | 撤退信号 |
| --- | --- | --- |
| 初次下洞 | 找入口周边、荧光果、基本地形 | 光源不足、护甲破、迷路 |
| 中期探索 | 找远古区、猴区、铥矿/雕像线索 | 背包满、理智失控、补给不足 |
| 遗迹推进 | 拿远古科技材料，规划战斗 | 梦魇阶段失控、多人掉队 |

## 什么时候做

地表有稳定食物、护甲、照明后再下洞更稳。熟手可以早下洞，但新手不要把洞穴当成开局捷径。

## 优先级清单

| 必带 | 用途 |
| --- | --- |
| 灯具和燃料 | 洞穴长期黑暗，备用光源就是生命线 |
| 护甲和武器 | 蠕虫、蜘蛛、蝙蝠、遗迹敌人都可能连锁 |
| 回血食物 | 洞穴受伤回家成本高 |
| 镐子/锤子 | 资源采集和路线处理 |
| 标记物/路线记忆 | 防迷路，尤其多人分散时 |

## 操作步骤

1. 第一次下洞只绕入口附近，建立心理地图。
2. 看到危险区域先标记，不要立刻深入。
3. 保持“能立刻回头”的补给线：光源低于安全线就撤。
4. 遗迹中留意梦魇循环变化，危险阶段不要贪雕像和战斗。
5. 多人下洞时保持集合点，掉队比单只怪更危险。

## 常见错误

| 错误 | 后果 | 改法 |
| --- | --- | --- |
| 只带一个光源 | 失误后直接黑暗死亡 | 至少两套照明方案 |
| 背包满还深入 | 无法拿关键资源，也难撤 | 到目标就回 |
| 不懂梦魇循环 | 被暗影怪和猴子节奏打崩 | 危险阶段收缩行动 |
| 进洞不告诉队友 | 死后没人知道尸体在哪 | 标记入口和路线 |
