## 结论速查

危机按 3 步处理：先离开危险源，再恢复生命/食物/光源，最后重建系统。没止损前不捡垃圾、不救远尸、不修装饰。

| 危机 | 第一动作 |
| --- | --- |
| 快饿死 | 停止项目，吃背包食物；没有食物就回锅/蜘蛛巢/浆果区 |
| 快没血 | 停战，穿护甲，吃回血；血量低于 50% 不继续输出 |
| 理智崩溃 | 补光，离开怪群，吃太妃糖/熟绿蘑菇或准备打暗影 |
| 基地起火 | 先救冰箱、锅、战斗箱、科技；普通材料烧了再补 |
| 猎狗来了 | 立刻离开核心区，去外场/牛群/猪房/陷阱线 |
| 队友死亡 | 报坐标/地标，清怪或引怪后再复活 |

## 什么时候做

任何危机都按“止损 -> 稳定 -> 复盘”三步处理。不要在还没止损时急着恢复原样。

## 优先级清单

| 阶段 | 动作 |
| --- | --- |
| 止损 | 离开危险源，保证光源、护甲、生命 |
| 稳定 | 补 2 份食物、1 件护甲、1 光源，复活队友 |
| 恢复 | 重建火坑、锅、冰箱、战斗箱、基础库存 |
| 复盘 | 把事故原因改成布局或库存规则 |

## 操作步骤

| 危机 | 操作顺序 |
| --- | --- |
| 死亡 | 报地标 -> 队友带护甲光源 -> 清怪/引怪 -> 复活/捡尸 |
| 捡尸 | 先拿备用护甲和光源；尸体旁有怪就先拉走 |
| 基地烧毁 | 重建火坑 -> 锅/冰箱 -> 科技 -> 战斗箱 -> 资源箱 |
| 饥荒 | 所有人停止长期项目；2 人找肉源，1 人做锅，1 人找填充物 |
| 团灭 | 若锅/冰箱/科技/资源箱全毁且入冬或入夏，开新世界；否则救 |

## 常见错误

| 错误 | 后果 | 改法 |
| --- | --- | --- |
| 裸身捡尸 | 二次死亡 | 先拿备用护甲和光源 |
| 猎狗进基地 | 仓库和建筑被毁 | 提前去外场处理 |
| 火灾时捡普通材料 | 损失核心科技和食物 | 先救关键建筑/箱 |
| 团队没人指挥 | 每个人都做一半 | 指定救场负责人 |
