## 结论速查

危机发生时，不要一边慌一边补救。先判断是哪一条线崩了：生命、食物、理智、季节、基地、队伍。

| 危机 | 第一动作 |
| --- | --- |
| 快饿死 | 停止远行，吃能吃的，回基地或找近食物 |
| 快没血 | 停战，穿护甲，吃回血，别继续贪 |
| 理智崩溃 | 补光、离开危险区、准备打暗影或恢复理智 |
| 基地起火 | 先救核心箱和科技，不要站火里捡垃圾 |
| 猎狗来了 | 离开基地核心，去开阔地或借助牛/猪/陷阱 |
| 队友死亡 | 先确认尸体位置和周围危险，再复活 |

## 什么时候做

任何危机都按“止损 -> 稳定 -> 复盘”三步处理。不要在还没止损时急着恢复原样。

## 优先级清单

| 阶段 | 动作 |
| --- | --- |
| 止损 | 活下来，离开危险源，保住关键物资 |
| 稳定 | 补光、补食物、补护甲、复活队友 |
| 恢复 | 重建仓库、补资源、重新规划防线 |
| 复盘 | 找出事故原因，改布局或流程 |

## 操作步骤

1. 死亡后先报位置，不要让队友盲找。
2. 捡尸前先清怪或引走怪，别连环死亡。
3. 基地烧毁后优先重建火坑、科技、冰箱/锅、战斗补给，不急着装饰。
4. 饥荒时不要继续做长期项目，所有人分头找短期食物。
5. 团灭后先判断世界是否值得救：季节、基地损失、关键资源、玩家耐心都要算。

## 常见错误

| 错误 | 后果 | 改法 |
| --- | --- | --- |
| 裸身捡尸 | 二次死亡 | 先拿备用护甲和光源 |
| 猎狗进基地 | 仓库和建筑被毁 | 提前去外场处理 |
| 火灾时捡普通材料 | 损失核心科技和食物 | 先救关键建筑/箱 |
| 团队没人指挥 | 每个人都做一半 | 指定救场负责人 |
