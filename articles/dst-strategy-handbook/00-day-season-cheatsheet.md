## 结论速查

默认世界节奏可以先按这个表判断。服务器改过季节长度时，以实际季节为准。

| 阶段 | 该做 | 不该做 | 下一步准备 |
| --- | --- | --- | --- |
| 第 1-3 天 | 探图、捡基础资源、做火把工具 | 原地建家、夜晚发呆 | 找金子和道路 |
| 第 4-7 天 | 科技解锁、背包、铲子、长矛、木甲 | 搬空全图资源 | 基地候选和食物系统 |
| 第 8-15 天 | 火坑、锅、冰箱、箱子、初步食物循环 | 只靠采集过日子 | 入冬资源 |
| 第 16-20 天 | 冬装、热源、木头、护甲、回血 | 远行不带回程计划 | 冬季和 Deerclops 风险 |
| 第 21-35 天 | 保暖、稳食物、控风险、补装备 | 裸奔、长途贪图 | 春季雨具和避雷 |
| 第 36-55 天 | 防雨、防雷、补夏季方案 | 基地无避雷、资源密堆 | 夏季降温防火 |
| 第 56-70 天 | 防过热、防自燃、地表少冒险 | 核心区点火打架 | 下一年循环和后期目标 |
| 第 70 天后 | Boss 循环、洞穴遗迹、库存维护 | 只造景不补给 | 长期世界规划 |

## 秋季：第 1-20 天

### 第 1-3 天

| 目标 | 做法 |
| --- | --- |
| 活过夜晚 | 手上永远留火把材料 |
| 提高效率 | 沿道路探图，优先捡草、树枝、燧石、食物 |
| 打开科技 | 找矿区或墓地附近的金子 |

不要：

- 不要第一天就决定永久基地。
- 不要为了砍树错过探图。
- 不要把所有食物都烤了吃掉，快腐食物先吃，耐放食物留给锅。

### 第 4-7 天

| 目标 | 做法 |
| --- | --- |
| 解锁基础科技 | 科学机器、背包、铲子、长矛、木甲 |
| 判断基地 | 找牛群、猪王、沙漠、沼泽、洞口、虫洞 |
| 准备食物系统 | 规划锅、冰箱、肉源和浆果/蔬菜来源 |

不要：

- 不要把基地建在沼泽、蜘蛛群、猎狗丘旁边。
- 不要把移植当主线，移植是基地稳定后的事情。

### 第 8-15 天

| 目标 | 做法 |
| --- | --- |
| 基地成型 | 火坑、箱子、锅、冰箱、科技建筑 |
| 食物稳定 | 蜘蛛/兔子/浆果/蔬菜/肉源至少确定一种 |
| 战斗准备 | 战斗箱放护甲、武器、回血、光源 |

不要：

- 不要让所有箱子无分类。
- 不要把可燃物密密麻麻堆在一起。

### 第 16-20 天

| 目标 | 做法 |
| --- | --- |
| 入冬准备 | 保暖、热源、木头、草、树枝、回血 |
| Boss 风险 | 准备外场，不在基地核心区打 |
| 食物储备 | 冰箱、肉干、锅料理，别只看背包食物 |

不要：

- 不要在最后几天才开始找保暖材料。
- 不要长期远行不带木头和火源。

## 冬季：第 21-35 天

| 问题 | 应对 |
| --- | --- |
| 冷 | 保暖装备、热源、回基地节奏 |
| 夜长 | 带足照明，少做无目标远行 |
| 食物少 | 依赖储备、肉源、锅料理，不只靠采集 |
| Boss 压力 | 护甲、回血、场地、撤退路线 |

不要：

- 不要在低温时硬跑远图。
- 不要在基地核心区处理大型威胁。
- 不要把所有回血留在箱子里。

下一步准备：[四季规划](04-seasonal-planning.html) 和 [战斗与 Boss 准备](06-combat-and-boss-prep.html)。

## 春季：第 36-55 天

| 问题 | 应对 |
| --- | --- |
| 雨和潮湿 | 雨具、控制理智、别让湿装备拖垮战斗 |
| 雷击 | 核心基地覆盖避雷 |
| 青蛙雨/生物骚扰 | 离开核心区处理，避免引进家 |
| 夏季将至 | 准备降温、防火、灭火或洞穴方案 |

不要：

- 不要让基地没有避雷针。
- 不要在雨季把理智和血量都压低。

下一步准备：[基地与动线](02-base-and-logistics.html) 和 [种地速查](12-farming-cheatsheet.html)。

## 夏季：第 56-70 天

| 问题 | 应对 |
| --- | --- |
| 过热 | 降温物、树荫、冷源、减少无意义地表奔波 |
| 自燃 | 核心区防火，资源分区，不把可燃物密堆 |
| 地表压力 | 需要时转入洞穴、前哨或短途行动 |
| 蚁狮/沙尘等机制 | 根据世界进度查当前版本细节 |

不要：

- 不要在基地旁点火、打高风险战斗。
- 不要把整个夏天当秋天玩。

下一步准备：[洞穴、遗迹与进度推进](07-caves-ruins-and-progression.html) 和 [后期循环](10-late-game-loop.html)。

## 常见错误

| 错误 | 为什么糟 | 改法 |
| --- | --- | --- |
| 只看今天，不准备下个季节 | 季节到来时来不及补系统 | 每个季节中段准备下个季节 |
| 一直探图不建食物系统 | 第一个冬天断粮 | 第 8-15 天必须转基地和食物 |
| 危险进基地处理 | 一次事故毁长期资源 | 战斗区和核心区分开 |
| 把攻略当固定流程 | 服务器设置和角色会改变节奏 | 用表格做判断，不死背步骤 |
