## 结论速查

默认世界按秋 20 天、冬 15 天、春 20 天、夏 15 天循环。服务器改过季节长度时，按右上角季节图标和实际天数执行同一套清单。

| 阶段 | 该做 | 不该做 | 下一步准备 |
| --- | --- | --- | --- |
| 第 1-3 天 | 探图，采 20 草/20 树枝/10 燧石，做火把、斧头、镐子 | 原地建家、夜晚发呆 | 找金子、道路、虫洞 |
| 第 4-7 天 | 解锁背包、铲子、长矛、木甲，标记牛群/猪王/沙漠/洞口 | 搬空全图资源 | 选基地，准备锅和冰箱材料 |
| 第 8-15 天 | 建火坑、锅、冰箱、6 个箱子，确定 1 个肉源和 1 个填充物来源 | 只靠采集过日子 | 冬装、热源、回血库存 |
| 第 16-20 天 | 做热能石、冬帽或牛帽，战斗箱放 2 套护甲、2 把武器、4 份回血 | 远行不带回程计划 | Deerclops 外场和春季避雷 |
| 第 21-35 天 | 每次出门带热源、光源、2 份食物、1 件护甲；补木头草树枝 | 裸奔、长途贪图 | 雨具、避雷针、春季食物 |
| 第 36-55 天 | 核心区插避雷针，准备雨具，做灭火/降温方案 | 基地无避雷、资源密堆 | 夏季降温、防火、洞穴方案 |
| 第 56-70 天 | 开启防火方案，核心区停止打架点火，地表行动控制在短途补给 | 核心区点火打架 | 下一年库存线和后期目标 |
| 第 70 天后 | 固定 Boss 战场、洞穴批次推进、每季补库存 | 只造景不补给 | 长期世界规划 |

## 秋季：第 1-20 天

### 第 1-3 天

| 目标 | 做法 |
| --- | --- |
| 活过夜晚 | 背包里始终保留 2 草 + 2 树枝，夜晚前 10 秒做火把 |
| 提高效率 | 沿道路和海岸线探图，草/树枝各到 20 后停止专门采集 |
| 打开科技 | 找 1 金子；第 4 天前必须能做科学机器 |
| 食物处理 | 浆果/胡萝卜快腐先吃；肉类和怪物肉留给锅 |

| 禁止动作 | 原因 |
| --- | --- |
| 第 1 天定永久基地 | 地图资源点未确认 |
| 白天原地砍一整片森林 | 探图时间被浪费 |
| 把所有食物烤完吃掉 | 第 8 天后没有锅食材 |

### 第 4-7 天

| 目标 | 做法 |
| --- | --- |
| 解锁基础科技 | 科学机器、背包、铲子、长矛、木甲 |
| 判断基地 | 至少确认牛群、洞口、沙漠、沼泽、虫洞中的 3 类位置 |
| 准备食物系统 | 收集锅材料：3 切石、6 木炭、6 树枝；记录齿轮来源 |
| 准备战斗 | 身上保持 1 木甲 + 1 长矛 |

| 禁止动作 | 原因 |
| --- | --- |
| 主基地贴沼泽/蜘蛛群/猎狗丘 | 小怪会进家 |
| 第 7 天前移植超过 10 个资源点 | 铲子时间和背包格被浪费 |

### 第 8-15 天

| 目标 | 做法 |
| --- | --- |
| 基地成型 | 火坑、6 箱、锅、冰箱、科学机器或炼金引擎 |
| 食物稳定 | 1 个肉源 + 1 个填充物来源 + 锅 + 冰箱全部到位 |
| 战斗准备 | 战斗箱放 2 木甲/头盔、2 长矛、4 回血料理、2 火把材料 |

| 禁止动作 | 原因 |
| --- | --- |
| 所有箱子无分类 | Boss 或猎狗来时找不到装备 |
| 草、树枝、浆果贴火坑密植 | 火灾会连锁烧毁 |

### 第 16-20 天

| 目标 | 做法 |
| --- | --- |
| 入冬准备 | 热能石 1、冬帽/牛帽 1、木头 40、草 40、树枝 40 |
| Boss 风险 | 基地外 1 屏以上清出战场，放火坑和战斗箱 |
| 食物储备 | 冰箱内至少 12 份可入锅食材，随身 2 份料理 |

| 禁止动作 | 原因 |
| --- | --- |
| 第 19 天才找保暖材料 | 冬天移动和采集成本上升 |
| 远行不带木头、草、树枝 | 无法临时做火把或营火 |

## 冬季：第 21-35 天

| 问题 | 应对 |
| --- | --- |
| 冷 | 热能石变冷后立刻回火源；远行只走已知路线 |
| 夜长 | 身上保留 2 火把材料或 1 矿工帽/提灯 |
| 食物少 | 用蜘蛛巢/兔子/库存做锅料理，不靠野外浆果 |
| Boss 压力 | 外场带 2 件护甲、2 把武器、4 份回血、1 个火源 |

| 禁止动作 | 原因 |
| --- | --- |
| 低温提示后继续跑远图 | 冻伤会和黑暗/怪物叠加 |
| 在基地核心区处理大型威胁 | 建筑和箱子会被毁 |
| 回血全留箱子里 | 战斗时无法使用 |

下一步准备：[四季规划](04-seasonal-planning.html) 和 [战斗与 Boss 准备](06-combat-and-boss-prep.html)。

## 春季：第 36-55 天

| 问题 | 应对 |
| --- | --- |
| 雨和潮湿 | 雨具穿上后再出门；低理智时停止远行 |
| 雷击 | 避雷针覆盖锅、冰箱、箱子、移植区 |
| 青蛙雨/生物骚扰 | 把青蛙引到基地外，停止在箱子区战斗 |
| 夏季将至 | 准备冰、硝石、灭火器或洞穴前哨 |

| 禁止动作 | 原因 |
| --- | --- |
| 核心区没有避雷针 | 一次雷击可点燃仓库 |
| 湿身、低血、低理智继续战斗 | 暗影怪和潮湿惩罚叠加 |

下一步准备：[基地与动线](02-base-and-logistics.html) 和 [种地速查](12-farming-cheatsheet.html)。

## 夏季：第 56-70 天

| 问题 | 应对 |
| --- | --- |
| 过热 | 冷热能石、冰、硝石火、冰箱补给线；过热提示后回冷源 |
| 自燃 | 可燃物分区，核心区覆盖灭火器或把夏季活动转入洞穴 |
| 地表压力 | 地表只做短途补给；长项目放洞穴或前哨 |
| 蚁狮/沙尘机制 | 夏季开始后查当前世界是否需要处理蚁狮供奉 |

| 禁止动作 | 原因 |
| --- | --- |
| 基地旁点火或打高风险战斗 | 自燃和战斗会同时毁家 |
| 夏季继续大规模地表建设 | 过热和自燃会打断节奏 |

下一步准备：[洞穴、遗迹与进度推进](07-caves-ruins-and-progression.html) 和 [后期循环](10-late-game-loop.html)。

## 常见错误

| 错误 | 为什么糟 | 改法 |
| --- | --- | --- |
| 只看今天，不准备下个季节 | 季节到来时来不及补系统 | 每个季节中段准备下个季节 |
| 一直探图不建食物系统 | 第一个冬天断粮 | 第 8-15 天必须转基地和食物 |
| 危险进基地处理 | 一次事故毁长期资源 | 战斗区和核心区分开 |
| 服务器季节长度改过还按默认天数走 | 准备时间错位 | 按季节图标套用对应清单 |
