## About This Series

Large language models like Claude can write code, answer questions, and reason about complex systems — but they cannot see or touch the world. To control a game engine, an LLM needs an interface: a structured way to read state, call functions, and receive results. That interface is called the Model Context Protocol (MCP). Several open-source projects have already built MCP servers for Unreal Engine, each taking a different approach. This series examines what they've built, how they work, and what's still missing.
