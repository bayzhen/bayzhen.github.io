## About This Series

RL Learner is a reinforcement learning training system built almost entirely by AI. It trains game-playing agents using PPO on GPU, running thousands of parallel football matches simultaneously. Simple environments converge quickly, but 11v11 football remains stubbornly unsolved. This series walks through the system piece by piece.

## What You'll Find

- An overview of the project and what makes AI-generated RL code interesting
- How PPO and GAE work together to train agents
- The CUDA-vectorized football environment that runs entirely on GPU
- A performance optimization journey from 7,300 to 1.2 million steps per second
- Why football AI refuses to learn — and what might finally crack it
