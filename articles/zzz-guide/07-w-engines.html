W-Engines Guide (W引擎指南)

Intermediate | 8-10 min read

What are W-Engines? (什么是W引擎?)

W-Engines (W引擎) are spherical (球形的) weapons that agents equip to enhance (增强) their combat performance. Each agent can equip one W-Engine.

W-Engine Components (W引擎组成)

  • Main Stat (主属性): Usually Base ATK (基础攻击力)
  • Sub Stat (副属性): Varies by engine (因引擎而异) (CRIT, ATK%, etc.)
  • W-Engine Effect (W引擎效果): Passive ability (被动能力)
Critical Rule (关键规则):
W-Engine Effects only activate (激活) when the agent's Specialty matches (专精匹配) the engine's specialty! Any agent can equip any engine, but mismatched (不匹配的) engines won't use their effect.

Rarity & Progression (稀有度与进阶)

Rarity Tiers (稀有度等级)

Rarity Base ATK Range (基础攻击范围) Source (来源)
S-Rank Highest Signal Search (Gacha) (信号搜索)
A-Rank Medium Signal Search, Crafting (制作)
B-Rank Low Crafting, Drops (掉落)

Upgrade Systems (升级系统)

  1. Enhancing (强化): Increases main stat using W-Engine EXP materials (使用W引擎经验材料提升主属性)
  2. Modification (改造): Every 10 levels, boosts both main and sub stats (每10级提升主副属性). Requires specialty-specific components (需要专精特定组件) and Dennies.
  3. Overclocking (超频): Uses duplicate (重复的) copies to improve W-Engine Effect (提升W引擎效果). Multiple phases (多个阶段) available.

Exclusive W-Engines (专属W引擎)

Each playable agent has a matching (匹配的) exclusive (专属的) W-Engine. When equipped (装备时), it unlocks unique visual effects (独特视觉效果) during combat.

Should You Pull for Signature W-Engines? (应该抽专武吗?)
Signature (专属) W-Engines are powerful but not mandatory (必须的). A-Rank alternatives (替代品) work well for most content. Prioritize (优先) new agents over weapons unless you're a whale (大氪玩家)!

Obtaining W-Engines (获取W引擎)

  • Signal Search (信号搜索): Main source for S-Rank engines
  • Box Galaxy (盒子银河): Craft A/B-Rank engines using W-Engine Chips (使用W引擎芯片制作)
  • Events (活动): Occasional (偶尔的) free engines
  • Battle Pass (战令): Selected A-Rank engines
