## How to Use This Glossary

This glossary is organized into categories. Each entry includes the English term, Chinese translation, and a brief definition. Terms marked with **[Dev]** are game development specific. Terms marked with **[Adv]** are advanced vocabulary beyond typical CET-6 level.

---

## 1. The Pitch (球场)

| English | 中文 | Definition |
| --- | --- | --- |
| Pitch | 球场 | The playing field |
| Halfway line | 中线 | The line dividing the pitch in two |
| Center circle | 中圈 | Circle at the center of the pitch (9.15m radius) |
| Penalty area / box | 禁区 | The large rectangle in front of the goal (16.5m deep) |
| Goal area / six-yard box | 球门区/小禁区 | The smaller rectangle in front of the goal (5.5m deep) |
| Penalty spot | 罚球点 | The spot 11m from the goal for penalty kicks |
| Corner arc | 角球区 | Quarter-circle at each corner of the pitch |
| Touchline / sideline | 边线 | The long boundary lines on each side |
| Goal line / byline | 底线/球门线 | The short boundary lines at each end |
| Technical area | 技术区 | The area where the coach stands during a match |
| Dugout / bench | 替补席 | Where substitutes and staff sit |

## 3. Match Events (比赛事件)

| English | 中文 | Definition |
| --- | --- | --- |
| Kick-off | 开球 | Start or restart of play at the center spot |
| Half-time | 中场休息 | Break between the two halves |
| Full-time | 全场结束 | End of the match |
| Stoppage time / injury time | 补时/伤停补时 | Extra time added by the referee for delays |
| Extra time | 加时赛 | Additional 30 minutes in knockout matches |
| Penalty shootout | 点球大战 | Deciding a match by alternating penalty kicks |
| Goal | 进球 | Ball crosses the goal line between the posts |
| Own goal | 乌龙球 | A player accidentally scores against their own team |
| Offside | 越位 | Illegal forward positioning at the moment of a pass |
| Foul | 犯规 | An illegal action against an opponent |
| Yellow card | 黄牌 | A caution / warning |
| Red card | 红牌 | Dismissal from the match |
| Free kick | 任意球 | Restart after a foul |
| Direct free kick | 直接任意球 | Can score directly without another touch |
| Indirect free kick | 间接任意球 | Must touch another player before a goal |
| Penalty kick | 点球 | A shot from the penalty spot for a foul in the box |
| Corner kick | 角球 | Restart from the corner after the ball crosses the goal line |
| Throw-in | 掷界外球 | Restart from the sideline |
| Goal kick | 球门球 | Restart from the goal area |
| Substitution | 换人 | Replacing one player with another |
| VAR (Video Assistant Referee) | 视频助理裁判 | Technology for reviewing referee decisions |

## 4. Actions and Techniques (动作与技术)

| English | 中文 | Definition |
| --- | --- | --- |
| Pass | 传球 | Moving the ball to a teammate |
| Through ball | 直塞球 | A pass played into space behind the defense |
| Cross | 传中 | A pass from a wide area into the penalty box |
| Lob | 挑传/吊球 | An aerial pass over defenders |
| Chip | 挑射 | A delicate shot lobbed over the goalkeeper |
| Shot | 射门 | Attempt to score |
| Volley | 凌空抽射 | Striking the ball mid-air before it bounces |
| Header | 头球 | Using the head to direct the ball |
| Dribble | 盘带 | Running with the ball at your feet |
| Skill move | 技巧动作 | A trick to beat a defender (step-over, roulette, etc.) |
| Tackle | 铲球/抢断 | Attempt to take the ball from an opponent |
| Sliding tackle | 铲球 | A tackle where the player slides along the ground |
| Interception | 拦截 | Cutting out an opponent's pass |
| Clearance | 解围 | Kicking the ball away from danger |
| Nutmeg [Adv] | 穿裆 | Passing the ball between an opponent's legs |
| Bicycle kick / overhead kick | 倒挂金钩 | An acrobatic kick with the player's back to the goal |
| Finesse shot [Adv] | 巧射 | A placed shot using curve rather than power |
| Knuckleball [Adv] | 电梯球 | A shot with minimal spin that swerves unpredictably |
| One-two / wall pass | 二过一/撞墙式配合 | A quick pass-and-return between two players |
| Dummy [Adv] | 假装接球 | Letting the ball pass through without touching it to deceive defenders |

## 5. Tactical Terms (战术术语)

| English | 中文 | Definition |
| --- | --- | --- |
| Formation | 阵型 | The arrangement of players on the pitch (e.g. 4-4-2) |
| Pressing | 逼抢 | Closing down opponents to win the ball |
| High press | 高位逼抢 | Pressing in the opponent's half |
| Low block | 低位防守 | Defending deep near your own goal |
| Counter-attack | 反击/快速反击 | Attacking quickly after winning the ball |
| Possession | 控球 | Maintaining the ball through passing |
| Tiki-taka [Adv] | 短传渗透 | A passing style emphasizing short passes and movement |
| Park the bus | 摆大巴 | Extreme defensive tactic with all players behind the ball |
| Man-marking | 人盯人 | Each defender follows a specific opponent |
| Zonal marking | 区域防守 | Defenders cover areas rather than specific players |
| Overlap | 套边 | A player running outside a teammate on the flank |
| Underlap [Adv] | 内切跑位 | A player running inside a teammate on the flank |
| Inverted winger [Adv] | 内切型边锋 | A winger who cuts inside to their strong foot |
| False nine [Adv] | 伪九号 | Striker who drops into midfield to create space |
| Pressing trigger | 逼抢触发条件 | The specific situation that initiates team pressing |
| Transition | 攻防转换 | The moment of switching between attack and defense |
| Build-up play | 组织进攻 | Constructing attacks from the back |
| Set piece | 定位球 | Planned routine for restarts (corners, free kicks) |
| Offside trap | 越位陷阱 | Defenders stepping forward to catch attackers offside |
| Compact shape [Adv] | 紧凑阵型 | Keeping players close together to deny space |

| Potential | 潜力值 | The maximum OVR a player can reach |

| Sprint speed | 冲刺速度 | Maximum running velocity |
| Shooting | 射门 | Finishing, shot power, and accuracy combined |

| Passing | 传球 | Short and long pass accuracy combined |
| Vision | 视野 | Ability to see and execute creative passes |
| Dribbling | 盘带 | Ball control, agility, and tricks combined |
| Agility | 灵活性 | Ability to change direction quickly |
| Balance | 平衡 | Stability when challenged by opponents |
| Defending | 防守 | Tackling, marking, and interception combined |
| Tackling | 铲抢 | Ability to win the ball from opponents |
| Physical | 身体素质 | Strength, stamina, and jumping combined |
| Stamina | 体力 | Endurance over a full match |
| Strength | 力量 | Physical power in challenges |
| Composure [Adv] | 沉着 | Performance quality under pressure |
| Work rate | 跑动积极性 | How much a player runs off the ball |
| Weak foot | 弱脚 | Ability with the non-preferred foot (rated 1-5 stars) |

## 7. Game Development Terms (游戏开发术语)

| English | 中文 | Definition |
| --- | --- | --- |
| **[Dev]** ECS (Entity-Component-System) | 实体-组件-系统 | Architecture pattern separating data from logic |
| **[Dev]** State machine / FSM | 状态机/有限状态机 | System that transitions between defined states |
| **[Dev]** Behavior tree | 行为树 | Tree-structured AI decision-making system |
| **[Dev]** Utility AI | 效用AI | AI that scores and picks the highest-value action |
| **[Dev]** Influence map | 影响力图 | Grid overlay showing tactical value per area |
| **[Dev]** Collision detection | 碰撞检测 | Detecting when game objects touch or overlap |
| **[Dev]** Rigid body | 刚体 | Physics object with mass and velocity |
| **[Dev]** Impulse | 冲量 | Instantaneous force applied to change velocity |
| **[Dev]** Coefficient of restitution | 恢复系数 | How much energy is preserved after a bounce (0 to 1) |
| **[Dev]** Magnus effect | 马格努斯效应 | Force on a spinning ball causing it to curve |
| **[Dev]** Drag (aerodynamic) | 空气阻力 | Force opposing motion through air |
| **[Dev]** Lerp (linear interpolation) | 线性插值 | Smoothly blending between two values |
| **[Dev]** Delta time (dt) | 帧间隔时间 | Time elapsed between two consecutive frames |
| **[Dev]** Motion capture (mocap) | 动作捕捉 | Recording real actor movements for animation |
| **[Dev]** Animation blending | 动画混合 | Smoothly transitioning between animations |
| **[Dev]** IK (Inverse Kinematics) | 反向运动学 | Calculating joint positions to reach a target |
| **[Dev]** Ragdoll | 布娃娃物理 | Physics-based body simulation (e.g. after a tackle) |
| **[Dev]** LOD (Level of Detail) | 细节层次 | Reducing model complexity for distant objects |
| **[Dev]** Netcode | 网络代码 | Networking implementation for multiplayer games |
| **[Dev]** Latency compensation | 延迟补偿 | Techniques to hide network delay from players |
| **[Dev]** Client-server | 客户端-服务器 | Architecture where a central server manages game state |
| **[Dev]** Deterministic simulation | 确定性模拟 | Same inputs always produce same outputs |
| **[Dev]** Rubber banding [Adv] | 橡皮筋效应 | Dynamic difficulty adjustment that feels artificial |
| **[Dev]** HUD (Heads-Up Display) | 抬头显示 | In-game overlay showing score, time, etc. |
| **[Dev]** Reticle | 准星 | Aiming indicator on screen |
