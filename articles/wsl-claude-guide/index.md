老公给你搭好了环境，但你完全不知道发生了什么？

别担心，这个系列就是为你写的。

我们会用最通俗的语言，把 Windows、WSL、Ubuntu、VS Code、Claude Code 这些听起来很吓人的东西，一个一个讲清楚。没有代码，没有术语轰炸，只有你能看懂的大白话和生动的比喻。

## 你能学到什么

- **搞清楚这些东西都是啥**：用生活中的例子，让你秒懂这些软件的关系
- **学会每天的操作流程**：打开电脑 → 启动软件 → 开始和AI聊天
- **掌握基本的文件操作**：创建文件夹、新建文件、找到自己的东西
- **学会和AI高效沟通**：让Claude Code更好地帮你工作
- **遇到问题不慌张**：常见问题都有对应的解决办法

## 适合谁看

- 完全不懂编程，但需要用AI辅助工作的你
- 老公/男朋友/同事帮你装好了环境，但你不知道怎么回事的你
- 想搞明白"我电脑里到底装了什么"的你

## 阅读建议

按顺序看就好，每篇都不长。看完第一篇概念篇，后面的操作篇就很容易理解了。

遇到不懂的地方，先别慌——往后看两行，可能就懂了。
