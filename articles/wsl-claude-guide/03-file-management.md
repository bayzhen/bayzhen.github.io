## 为什么要学文件管理？

因为你和 Claude Code 合作的时候，经常需要：
- 告诉它"帮我看一下某个文件"
- 把某个文件放到正确的位置
- 创建一个新文件让它帮你写东西

这就像你去超市之前要知道"冰箱在厨房，调料在橱柜"一样——知道东西在哪，才能高效工作。

先看一张图，理解文件管理的核心思路：

![文件管理就像整理衣柜](/assets/images/wsl-claude-guide/file-system.svg)

---

## 核心概念：文件夹就是"收纳盒"

你家里是怎么整理东西的？

- 衣服放**衣柜**里
- 衣柜里分**上衣区、裤子区、鞋子区**
- 上衣区里有**衬衫、T恤、毛衣**

电脑里完全一样：

- 所有东西放在**硬盘**里
- 硬盘里分成不同的**文件夹**
- 文件夹里放着**文件**（文档、图片、表格等等）
- 文件夹里还可以再建**子文件夹**（就像大盒子里套小盒子）

**记住这一点：文件夹 = 收纳盒，文件 = 盒子里的东西。**

---

## 在 VS Code 里看文件

打开 VS Code 连接到 Ubuntu 之后，看**左边的侧边栏**：

那里就是你的"文件管理器"。你能看到：
- 📁 文件夹（前面有个小三角 ▶，点击可以展开/收起）
- 📄 文件（点击就能打开编辑）

**常用操作：**

### 展开/收起文件夹
- 点击文件夹名字前面的 **小三角 ▶** → 展开，看到里面的内容
- 再点一下 → 收起来

### 打开文件
- **单击** 文件名 → 预览模式（标签页标题是*斜体*的，再点其他文件就会被替换）
- **双击** 文件名 → 正式打开（标签页标题是正常字体，不会被替换）

> 小技巧：如果你打开一个文件后，点另一个文件第一个就消失了——那是因为你只单击了。下次试试**双击**！

## 创建新文件夹

当你需要一个新的"收纳盒"来放东西时：

### 方法一：右键菜单（推荐新手用这个）

1. 在左侧文件列表的**空白处**（或者某个文件夹上）**右键单击**
2. 选择 **"新建文件夹"**（英文是 `New Folder`）
3. 输入文件夹的名字，按**回车**

### 方法二：用小图标

1. 把鼠标移到左侧文件列表的标题栏上
2. 你会看到几个小图标出现
3. 点击**看起来像文件夹带个加号的那个图标** 📁+
4. 输入名字，回车

### 方法三：让 Claude Code 帮你（最省事！）

在终端里告诉 Claude Code：

```
帮我在当前目录下创建一个叫"工作报告"的文件夹
```

它会帮你搞定！

## 创建新文件

### 方法一：右键菜单

1. 在左侧文件列表中，**右键点击**你想放文件的文件夹
2. 选择 **"新建文件"**（英文是 `New File`）
3. 输入文件名（比如 `周报.md`），按**回车**
4. 文件会自动打开，你就可以开始写了

### 方法二：用小图标

和创建文件夹类似，找那个**看起来像文件带个加号的图标** 📄+

### 方法三：让 Claude Code 帮你

```
帮我创建一个文件叫"本周总结.md"，先写个框架
```

它不仅会创建文件，还会帮你写好内容框架！

## 文件命名小贴士

给文件起名的时候，注意这几点：

- ✅ **用英文、数字、短横线** → `week-report.md`、`data-2024.csv`
- ✅ **可以用中文** → `工作报告.md`（在 Ubuntu 里通常没问题）
- ❌ **不要用空格** → ~~`work report.md`~~（容易出问题）
- ❌ **不要用特殊符号** → ~~`报告@#$.md`~~

文件名后面的 `.md`、`.txt`、`.csv` 叫做"后缀名"或者"扩展名"，它告诉电脑这是什么类型的文件：

| 后缀 | 类型 | 相当于 |
|------|------|-------|
| `.md` | Markdown 文档 | 一种好看的文本格式 |
| `.txt` | 纯文本 | 最简单的文字文件 |
| `.csv` | 表格数据 | 简易版 Excel |
| `.py` | Python 代码 | 让AI帮你写的程序 |

## 移动和重命名

### 重命名文件/文件夹

1. 在左侧**右键点击**要改名的文件或文件夹
2. 选择 **"重命名"**（英文是 `Rename`）
3. 输入新名字，按回车

或者选中文件后按键盘的 **F2** 键。

### 移动文件

在左侧文件列表中，**拖动**文件到目标文件夹上，松手就好了。

就像把衣服从一个格子拿到另一个格子。

---

## 删除文件

1. **右键点击**要删除的文件或文件夹
2. 选择 **"删除"**（英文是 `Delete`）
3. 会弹出确认提示，点"确定"

> 温馨提醒：删除后可能无法恢复！不确定的话先别删。可以先改个名字加上"备份"两个字，比如 `周报-备份.md`。

## 让 Claude Code 帮你管文件

其实你不需要记住所有操作。Claude Code 可以帮你做大部分文件管理工作！

你可以这样说：

| 你说的话 | Claude Code 会做什么 |
|---------|-------------------|
| "帮我看看当前文件夹里有什么" | 列出所有文件和文件夹 |
| "创建一个叫'项目资料'的文件夹" | 创建文件夹 |
| "把 report.md 移到 archive 文件夹里" | 移动文件 |
| "帮我把这个文件改名为 final-report.md" | 重命名文件 |
| "这个文件里写了什么？" | 读取并展示文件内容 |

**这是最轻松的方式——动动嘴就行！**

## 两个世界的文件

这里要提醒你一个重要的事情：

你的电脑现在有**两个"世界"的文件**：

1. **Windows 世界**：你在桌面上、我的电脑里看到的文件（被公司加密的）
2. **Ubuntu 世界**：你在 VS Code 左侧看到的文件（在密室里，没有加密）

**这两个世界的文件是分开的！**

- 你在 Windows 桌面上放的文件，VS Code 里看不到
- 你在 VS Code（Ubuntu）里创建的文件，在 Windows 桌面上也看不到

如果需要把 Windows 里的文件搬到 Ubuntu 里使用，可以用**拖拽**的方式：
1. 在 Windows 文件管理器里找到文件
2. 直接**拖到 VS Code 的左侧文件列表**里
3. 文件就复制过去了

或者直接告诉 Claude Code："我桌面上有个文件叫 xxx，帮我复制到这里来"。
