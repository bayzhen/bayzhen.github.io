## 今天的目标

学会每天开机后的完整操作流程。做完这4步，你就可以开始和AI聊天工作了。

先看总览图，心里有个数：

![每天的开工流程](/assets/images/wsl-claude-guide/workflow.svg)

是不是看起来没那么可怕？下面我们一步一步来。

---

## 第1步：打开 VS Code

还记得吗？VS Code 是你的"万能遥控器"。

**找到它：**
- 在桌面上找到 **VS Code 的图标**（一个蓝色的、像折纸一样的图标）
- 或者点击任务栏（屏幕最下面那一条）上的 VS Code 图标
- 找不到的话，按键盘上的 **Windows 键**（左下角那个有 Windows 标志的键），然后打字输入 `Visual Studio Code`，回车

**双击打开它！**

> 打开后你会看到一个深色的界面——别被吓到，这就是正常的样子。程序员喜欢深色界面，据说对眼睛好。

---

## 第2步：确认连接到了 Ubuntu

这一步非常关键！你需要确认遥控器（VS Code）已经连上了密室（Ubuntu）。

**怎么看？** 看 VS Code 界面的**左下角**：

- ✅ 如果显示绿色的 **`WSL: Ubuntu`** → 恭喜，你已经连上了！跳到第3步
- ❌ 如果左下角是蓝色的 **`><`** 符号，或者什么都没有 → 需要手动连接

**手动连接的方法：**

1. 点击左下角那个蓝色的 **`><`** 符号（或者绿色的图标）
2. 屏幕顶部中间会弹出一个选择列表
3. 找到并点击 **"连接到 WSL"**（英文是 `Connect to WSL`）
4. 等几秒钟...左下角变成绿色的 `WSL: Ubuntu` 就成功了！

> 大多数情况下，VS Code 会自动记住上次的连接。所以通常打开就已经是绿色的了。但如果不是，按上面的步骤操作就好。

---

## 第3步：打开你的工作文件夹

连上密室后，你需要告诉 VS Code "我要在哪个文件夹里工作"。

**如果左侧已经显示了你的文件列表** → 说明已经打开了一个文件夹，可以直接用。

**如果左侧是空的，或者不是你想要的文件夹：**

1. 点击顶部菜单栏的 **"文件"**（英文是 `File`）
2. 选择 **"打开文件夹..."**（英文是 `Open Folder...`）
3. 在弹出的列表中，导航到你的工作目录
4. 选好后点 **"确定"**

你老公应该已经帮你建好了工作文件夹。如果不确定在哪里，**常见的位置是**：
- `/home/你的用户名/` 下面的某个文件夹
- 比如 `/home/wifename/work/` 或者 `/home/wifename/projects/`

> 不确定文件夹在哪？直接问你老公："我的工作文件夹路径是什么？"记下来，以后每次都打开同一个就好。

---

## 第4步：启动 Claude Code

终于到了和AI见面的时刻！

**打开终端（小黑窗）：**

你需要在 VS Code 里打开一个"终端"——就是那个黑色的小窗口。

- 方法一：按键盘快捷键 **Ctrl + ~**（Ctrl 键 + 左上角数字1旁边的波浪线键）
- 方法二：点击顶部菜单 **"终端"** → **"新建终端"**（英文是 `Terminal` → `New Terminal`）
- 方法三：点击顶部菜单 **"查看"** → **"终端"**

终端打开后，你会在 VS Code 的下半部分看到一个黑色区域，里面有类似这样的文字：

```
user@ubuntu:~/work$
```

这是终端在告诉你："我准备好了，等你的指令。"

**输入启动命令：**

在终端里输入以下内容，然后按 **回车键**：

```
claude
```

没错，就一个单词！

等几秒钟，你应该会看到 Claude Code 的欢迎界面。如果看到了类似 "我能帮你什么？" 的提示——恭喜你，AI小助手已经就位！

---

## 来看看完整的界面

现在你的 VS Code 应该是这个样子：

![VS Code 界面地图](/assets/images/wsl-claude-guide/vscode-layout.svg)

记住三个关键区域：
1. **左侧** → 文件列表（你的文件和文件夹都在这里）
2. **右上** → 编辑区（打开文件后在这里看和编辑内容）
3. **右下** → 终端（Claude Code 就在这里和你聊天！）

---

## 和 Claude Code 聊天

现在你可以在终端里和 Claude Code 对话了！

**怎么聊？**

直接打字输入你的需求，然后按**回车**发送。比如：

```
帮我写一份本周的工作周报模板
```

```
帮我分析一下这个Excel文件的数据
```

```
这段话帮我翻译成英文
```

Claude Code 会读取你工作文件夹里的文件，然后帮你完成任务。它可能会创建新文件、修改现有文件，或者直接回答你的问题。

> 就像和一个超级聪明的同事发微信一样——你说需求，它帮你做。

---

## 收工下班

工作完成后：

1. 在终端里输入 `/exit` 并回车，退出 Claude Code
2. 直接关闭 VS Code 窗口就行了

就这么简单！

---

## 快速回顾

每天开工只需要：

| 步骤 | 操作 | 耗时 |
|------|------|------|
| 1 | 双击打开 VS Code | 3秒 |
| 2 | 确认左下角是绿色 `WSL: Ubuntu` | 2秒 |
| 3 | 确认左侧有你的文件夹 | 2秒 |
| 4 | 打开终端，输入 `claude`，回车 | 10秒 |

**总计不到20秒！** 比泡一杯咖啡快多了。

熟练以后，这些步骤会变成肌肉记忆，就像打开手机解锁一样自然。

---

## 如果哪一步出了问题

先别慌！看看是不是这些情况：

- **VS Code 打不开** → 重启电脑试试
- **左下角不是绿色** → 回到第2步，手动连接
- **终端输入 claude 没反应** → 确认左下角是绿色的，然后关掉终端重新打开一个
- **什么都不行了** → 找老公！（这就是老公存在的意义之一嘛~）

更详细的问题排查，可以看本系列的第5篇《遇到问题别慌》。
