## 问题1：VS Code 左下角没有绿色标志

**症状：** 打开 VS Code 后，左下角没有显示绿色的 `WSL: Ubuntu`。

**原因：** VS Code 还没连上"密室"（Ubuntu）。

**解决：**

1. 看看左下角有没有一个 **蓝色的 `><` 符号**
2. 如果有，点击它
3. 在弹出的列表中选择 **"连接到 WSL"**（或 `Connect to WSL`）
4. 等几秒钟，左下角变成绿色就好了

**如果连 `><` 符号都没有：**
1. 按 `Ctrl + Shift + X` 打开扩展商店
2. 在搜索框里输入 `WSL`
3. 找到 **"WSL"** 这个扩展（微软出品的，有个企鹅图标）
4. 点击"安装"
5. 装好后重启 VS Code，再试一次

> 还不行？这个问题可能需要你老公来处理。别自己折腾太久，省下时间喝杯奶茶。

---

## 问题2：输入 claude 没反应或报错

**症状：** 在终端里输入 `claude` 后，没有出现AI助手，或者出现红色错误文字。

**先检查：** 左下角是不是绿色的 `WSL: Ubuntu`？如果不是，先解决问题1。

**如果已经连上了 Ubuntu，试试这些：**

**步骤1：关掉终端重新开**
1. 在终端右上角找到一个垃圾桶图标 🗑️，点击它（关闭终端）
2. 按 `Ctrl + ~` 重新打开一个终端
3. 输入 `claude` 试试

**步骤2：检查网络**

Claude Code 需要联网才能工作。确保你的电脑可以上网。
- 打开浏览器随便搜个东西，看能不能上网
- 如果不能上网，先连网

**步骤3：看看报错说了什么**

如果终端显示了红色或黄色的文字，那是"错误信息"。虽然你可能看不懂，但可以：
1. 用鼠标**选中**那些错误文字（点住拖动）
2. 按 `Ctrl + C` 复制
3. 发给你老公看——他能看懂！

## 问题3：找不到文件了

**症状：** 左侧文件列表里看不到你要的文件。

**可能的原因和解决方法：**

**原因A：打开了错误的文件夹**
1. 点击菜单 **文件 → 打开文件夹**
2. 选择正确的工作目录
3. 不确定路径？问 Claude Code：`我的文件都在哪里？帮我列出来`

**原因B：文件在 Windows 里而不是 Ubuntu 里**

记住：VS Code 连接 Ubuntu 后，看到的是 Ubuntu 里的文件。如果文件在 Windows 桌面上，你需要把它拖到 VS Code 里。

**原因C：文件被放到了子文件夹里**

点击左侧的小三角 ▶ 展开所有文件夹，仔细看看是不是在某个子文件夹里。

或者直接问 Claude Code：
```
帮我在当前目录下搜索所有包含"周报"两个字的文件
```

## 问题4：终端里全是看不懂的东西

**症状：** 终端里出现了一堆英文或奇怪的符号，你不知道发生了什么。

**别慌，这通常不是什么大问题。**

**最简单的解决方案——清屏：**
- 在终端里输入 `clear` 然后回车 → 屏幕就干净了
- 或者按 `Ctrl + L` 也行

**如果 Claude Code 还在运行：**
- 按 `Ctrl + C` → 这是"停止"的意思，可以中断当前操作
- 然后重新输入你的需求

**如果终端完全乱了：**
- 关掉这个终端（点垃圾桶图标 🗑️）
- 打开一个新的终端（`Ctrl + ~`）
- 重新输入 `claude`

---

## 问题5：Claude Code 回复了但我不满意

**症状：** Claude Code 做的事情不是你想要的。

**这个完全正常！就像和同事沟通一样，有时候需要多说几次。**

**试试这样说：**

```
这不是我想要的。我想要的是___，请重新帮我做一下。
```

```
方向不对。我的需求是___，请注意___这个要点。
```

```
差不多了，但是请把___部分修改一下，改成___。
```

如果它修改了文件但改错了，你可以说：
```
请撤销刚才的修改
```

## 问题6：VS Code 变得很卡或很慢

**可能的原因：**
- 打开了太多标签页（编辑区上面一排）
- 电脑内存不足

**解决方法：**
1. 关掉不需要的标签页（标签上有个 × 号，点击关闭）
2. 关掉不需要的其他程序（浏览器标签页太多也会卡）
3. 如果还是卡，重启 VS Code

---

## 问题7：不小心删错了文件

**别慌！**

**方法1：如果用的是 Claude Code 删的**

Claude Code 在删除文件前通常会先问你确认。如果已经删了，可以试着问它：
```
刚才删除的文件能恢复吗？
```

**方法2：如果是自己在VS Code里删的**

VS Code 删除的文件有时候会在回收站里。可以去看看：
- 在 Ubuntu 终端里，输入 `ls ~/.local/share/Trash/files/` 看看有没有

**方法3：找老公**

如果文件很重要，赶紧告诉你老公，让他帮你看看有没有办法恢复。越早说越好！

## 万能急救三步法

不管遇到什么问题，这三步通常都管用：

### 第一步：关掉重来
1. 关掉 VS Code
2. 重新打开 VS Code
3. 确认左下角是绿色的 `WSL: Ubuntu`
4. 打开终端，输入 `claude`

### 第二步：重启电脑
如果关掉重来不管用，重启电脑。很多问题重启就能解决——这不是笑话，是真的。

### 第三步：找老公
如果前两步都不管用，说明问题超出了日常使用的范围。把你看到的错误信息截图发给老公，让他远程帮你看看。

## 有用的键盘快捷键

最后附一份"快捷键小抄"，打印出来贴在显示器旁边也行：

| 快捷键 | 作用 | 什么时候用 |
|--------|------|----------|
| `Ctrl + ~` | 打开/关闭终端 | 要和Claude聊天的时候（波浪线键在数字1左边） |
| `Ctrl + S` | 保存文件 | 编辑完文件后 |
| `Ctrl + Z` | 撤销 | 打字打错了 |
| `Ctrl + C` | 停止/中断 | 终端里卡住了 |
| `Ctrl + L` | 清屏 | 终端太乱了 |
| `Ctrl + Shift + P` | 命令面板 | 找各种功能 |
| `F2` | 重命名 | 改文件名 |
