## Claude Code 是个什么样的助手？

在正式学"聊天技巧"之前，先了解一下 Claude Code 的特点：

**它很聪明：**
- 它能理解中文（也能理解英文、日文等等）
- 它能读你的文件、写文件、创建文件夹
- 它能分析数据、写文档、翻译、总结
- 它记得你们这次对话中说过的话

**但它也有局限：**
- 它看不到你的屏幕（你得用文字告诉它你要什么）
- 它每次对话的记忆是有限的（关掉再开就不记得之前聊的了）
- 它偶尔会犯错（就像同事也会犯错一样）

把它想象成一个**超级能干但是需要你说清楚需求的远程助手**——你发文字消息给它，它帮你做事。

---

## 聊天基础操作

### 怎么发消息

在 VS Code 下面的终端里，直接打字，然后按**回车**发送。

### 怎么看回复

发送后稍等一会，Claude Code 会在终端里显示回复。如果内容很长，你可以**向上滚动**查看完整的回复。

### 怎么结束对话

输入 `/exit` 然后回车。想重新开始新对话，再输入 `claude` 就行。

## 说话的艺术：怎么让AI更懂你

和 Claude Code 聊天最重要的原则：**说清楚、说具体**。

### 不太好的说法 vs 好的说法

| 不太好 | 好的说法 | 为什么好？ |
|-------|---------|---------|
| "帮我写个东西" | "帮我写一份本周工作周报，包含项目进度、遇到的问题和下周计划" | 明确了要写什么、包含哪些内容 |
| "看看这个文件" | "帮我看看 report.md 这个文件，总结一下里面的核心观点" | 明确了看哪个文件、看完要做什么 |
| "改一下" | "帮我把这份报告的语气改得更正式一些，适合发给领导看" | 明确了改什么、改成什么样 |
| "有个表格" | "帮我把 data.csv 里的销售数据做个分析，按月份汇总" | 明确了哪个文件、做什么分析 |

### 万能句式

这几个句式特别好用，建议收藏：

**1. "帮我___，要求是___"**
```
帮我写一封邮件回复客户，要求是礼貌但明确地拒绝降价请求
```

**2. "看看___文件，然后___"**
```
看看 meeting-notes.md 文件，然后帮我提取里面的待办事项，整理成清单
```

**3. "把___改成___"**
```
把这份文档里所有的"我们公司"改成"本公司"
```

**4. "参考___的格式，帮我写___"**
```
参考上周的周报格式，帮我写这周的周报，内容是：完成了XX项目的数据分析
```

## 实用场景示例

### 场景1：写文档

```
帮我写一份项目总结文档，包含以下几个部分：
1. 项目背景（简要说明）
2. 完成的工作（列清单）
3. 遇到的问题及解决方案
4. 下一步计划

项目名称是"客户满意度调研"，上周完成了问卷设计和发放，收回了200份有效问卷。
```

### 场景2：分析文件

```
帮我看看当前文件夹里所有的 .csv 文件，告诉我每个文件里有什么数据，分别有多少行
```

### 场景3：整理信息

```
我要给领导汇报这周的工作，帮我把以下零散的信息整理成一段通顺的汇报：
- 周一开了项目启动会
- 周二周三做数据清洗
- 周四发现数据有异常，排查了半天
- 周五写了分析报告初稿
```

### 场景4：翻译

```
帮我把下面这段英文邮件翻译成中文，保持商务邮件的语气：

Dear team, I would like to schedule a meeting next Monday to discuss the Q2 roadmap...
```

### 场景5：改写和润色

```
帮我把下面这段话改得更专业、更正式：

"这个方案我觉得还行吧，主要就是把数据弄一弄，然后出个报告。"
```

## 当 Claude Code 要操作文件时

Claude Code 帮你工作的时候，经常会需要创建或修改文件。这时候它会**先告诉你它要做什么**，然后**等你确认**。

你会看到类似这样的提示：

```
我将要创建文件 weekly-report.md，包含以下内容...
是否继续？(y/n)
```

- 输入 **y**（yes 的意思）然后回车 → 同意，让它继续
- 输入 **n**（no 的意思）然后回车 → 拒绝，不要执行这个操作

> 不确定的时候，可以先输入 n 拒绝，然后问它："你打算做什么？再详细解释一下"

## 对话中的小技巧

### 1. 可以追问和补充

一次对话中，你可以不断追问：

```
你：帮我写个周报
Claude：（写了一份周报）
你：不错，但是再加上"本周参加了客户拜访"这个内容
Claude：（修改后的周报）
你：语气再口语化一点
Claude：（再次修改）
```

### 2. 可以让它参考已有文件

```
参考 last-week-report.md 的格式和风格，帮我写这周的周报
```

Claude Code 会自动去读那个文件，然后模仿它的格式。

### 3. 不满意就说

```
这不是我想要的，我要的是...
```

直接说就好，不用客气。它不会生气的！

### 4. 复杂任务可以分步骤

如果你的需求比较复杂，可以一步步来：

```
第一步：先帮我看看 data 文件夹里有哪些文件
```

看完结果后：

```
第二步：帮我把 sales-2024.csv 的数据按月份汇总
```

然后：

```
第三步：把汇总结果写成一份分析报告
```

## 几个常用命令

在 Claude Code 的终端里，有几个特殊命令（以 `/` 开头的）：

| 命令 | 作用 |
|------|------|
| `/exit` | 退出 Claude Code |
| `/clear` | 清除当前对话历史，重新开始 |
| `/help` | 显示帮助信息 |

> 正常聊天的时候不需要加 `/`，直接打字说话就行。只有这几个特殊命令才需要。

## 本篇小结

和 Claude Code 聊天的核心要领：

1. **说清楚你要什么**（具体的比模糊的好）
2. **说清楚背景和要求**（给谁看的、什么风格、什么格式）
3. **不满意就直说**（它不会记仇的！）
4. **复杂的事情分步做**（一次一个小目标）
5. **它问你确认的时候，看清楚再决定**（y 确认，n 拒绝）

记住：Claude Code 就像一个随叫随到的超级助手。你越会"指挥"它，它就越能帮到你。
