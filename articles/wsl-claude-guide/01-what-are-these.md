## Windows —— 你的"房子"

**Windows 就是你电脑的操作系统。**

你每天开机看到的桌面、任务栏、开始菜单——这些都是 Windows。你可以把它想象成**你住的房子**。

你在这个房子里：
- 打开文件夹看文件（打开衣柜找衣服）
- 用浏览器上网（打开窗户看外面）
- 用微信聊天（用对讲机和朋友说话）

**总结：Windows = 你的房子，是一切的基础。**

> 你已经用了很多年的 Windows 了，只是以前不知道它叫这个名字而已。

---

## 公司加密 —— 为什么不能直接用AI？

你公司的电脑有一个特殊的设定：**所有文件都会被自动加密**。

这就好比你住的房子被安装了一把"超级锁"——你能在房子里正常生活，但如果有个新朋友（比如 Claude Code）想来你家帮忙干活，这把锁就不让它进门。

所以，你老公想了一个聪明的办法：**在房子里建一个不受这把锁影响的密室！**

---

## Linux 和 Ubuntu —— "密室"的故事

### Linux 是什么？

**Linux 是另一种操作系统**，就像 Windows 是一种操作系统一样。

打个比方：
- **Windows** 就像是**精装修的商品房**——开箱即用，有好看的桌面、鼠标点点点就能操作
- **Linux** 更像是**毛坯房**——没有那么多花哨的装修，但特别结实、特别灵活，程序员们超爱它

世界上绝大部分的服务器（就是那些支撑着微信、淘宝、抖音运行的超级电脑）都在用 Linux。

### Ubuntu 又是什么？

**Ubuntu 是 Linux 的一个"品牌"。**

Linux 就像"手机操作系统"这个大类，而 Ubuntu 就像其中的一个品牌——就像安卓手机里有华为、小米、OPPO 一样。Ubuntu 是 Linux 世界里最受欢迎的一个版本，因为它对新手比较友好。

**总结：Linux = 一种操作系统大类，Ubuntu = 其中一个品牌。**

---

## WSL —— 房子里的"密室"

好了，重点来了！

**WSL** 的全名是 **Windows Subsystem for Linux**（Windows 的 Linux 子系统）。

翻译成人话就是：**微软允许你在 Windows 这个"房子"里，开辟一个小房间，运行 Linux 系统。**

还记得前面说的吗？你公司的加密锁管不到这个小房间！所以：

- 🏠 **Windows**（房子）→ 被公司加密锁管着
- 🚪 **WSL**（密室入口）→ 一扇通往新世界的门
- 🏡 **Ubuntu**（密室）→ 一个自由的小天地，加密锁管不到这里

**这就是为什么你老公要装 WSL——它是解决公司加密限制的关键！**

> 你不需要亲自操作 WSL，它在幕后默默工作。你只要知道"我的 AI 助手住在密室里"就够了。

---

## VS Code —— 你的"万能遥控器"

**VS Code**（全名 Visual Studio Code）是微软做的一个软件。

你可以把它想象成一个**万能遥控器**——通过它，你可以：

- ✏️ **写东西**：就像一个高级记事本，可以写文字、编辑文件
- 📂 **管文件**：像文件管理器一样，帮你浏览、创建、删除文件
- 🔌 **连密室**：最重要的功能！它能"伸进"WSL 密室里，让你操作 Ubuntu 里的东西
- 💬 **和AI聊天**：Claude Code 就运行在 VS Code 的终端（一个小黑窗）里

**为什么要用 VS Code，而不是直接打开文件夹？**

因为你的工作文件在"密室"（Ubuntu）里，普通的文件管理器看不到密室里的东西。只有 VS Code 这个特殊的遥控器能"伸手"进去。

**总结：VS Code = 你操控一切的万能遥控器。**

---

## Claude Code —— 你的AI小助手

终于到主角了！

**Claude Code 是一个AI助手**，它能帮你：

- 📝 写文档、整理资料
- 📊 分析数据
- 💡 回答各种问题
- 🔧 帮你完成各种电脑上的工作

它住在哪里呢？**住在密室（Ubuntu）里**！

你怎么和它聊天呢？**通过 VS Code 的终端（小黑窗）**！

把它想象成：你用遥控器（VS Code）打开密室（Ubuntu）的门，然后和住在里面的小助手（Claude Code）对话。

---

## 来，串起来！

现在让我们把所有的概念串成一个故事：

> **你的公司电脑**（Windows 房子）装了加密锁，AI进不来。
>
> 于是你老公在房子里建了一个**密室**（通过 WSL 安装了 Ubuntu）。
>
> 然后他给了你一个**万能遥控器**（VS Code），让你能打开密室的门。
>
> 密室里住着一个**AI小助手**（Claude Code），随时准备帮你干活。
>
> 你每天要做的就是：**拿起遥控器 → 打开密室 → 和小助手聊天**。就这么简单！

## 一句话记住它们

|------|---------|---------|

| **Ubuntu** | 一种 Linux 系统 | 密室本身 |
| **VS Code** | 编辑器 + 远程连接工具 | 万能遥控器 |
