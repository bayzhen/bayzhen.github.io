## About This Series

NVIDIA Warp is an open-source Python framework that lets you write GPU-accelerated simulation and graphics code without leaving Python. It compiles your Python functions into efficient CUDA kernels at runtime, making it possible to run physics simulations, robotics workflows, and AI training pipelines at near-native GPU speed. This series is for developers who want to understand how Warp works and why it matters — no prior CUDA experience required.

## What You'll Find

- **Article 1 — What Is NVIDIA Warp?** An overview of the framework: what problem it solves and how it fits into the GPU computing landscape.
- **Article 2 — Kernel-Based Programming** How Warp's JIT compiler turns Python functions into GPU kernels, and what the programming model looks like.
- **Article 3 — Differentiable Simulation** Why differentiability matters for AI, and how Warp makes physics gradients flow through PyTorch and JAX.
- **Article 4 — Physics with warp.sim** The built-in simulation module: rigid bodies, soft bodies, and articulated robots in a few lines of Python.
- **Article 5 — Real-World Applications** Where Warp is being used today — robotics training, data generation, and integration with NVIDIA Omniverse.
