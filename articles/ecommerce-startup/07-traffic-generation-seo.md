## SEO Fundamentals

### How Search Engines Work

1. **Crawling**: Bots discover your pages
2. **Indexing**: Pages added to search database
3. **Ranking**: Algorithm determines position

**Goal**: Rank on first page for relevant keywords

> **Vocabulary**:
> - **crawling** /ˈkrɔːlɪŋ/ - 爬取
> - **algorithm** /ˈælɡərɪðəm/ - 算法

### Keyword Research

**Types of Keywords**:

**Informational** (Top of funnel):
- "how to choose yoga mat"
- "best yoga mat for beginners"
- Low buying intent, high traffic

**Commercial** (Middle of funnel):
- "yoga mat reviews"
- "eco-friendly yoga mat comparison"
- Medium buying intent

**Transactional** (Bottom of funnel):
- "buy cork yoga mat"
- "yoga mat free shipping"
- High buying intent, lower traffic

> **Vocabulary**:
> - **funnel** /ˈfʌnl/ - 漏斗（营销术语）
> - **intent** /ɪnˈtent/ - 意图
> - **transactional** /trænˈzækʃənl/ - 交易的

### Keyword Research Tools

**Free Tools**:
- **Google Keyword Planner**: Search volume data
- **Google Autocomplete**: Suggested searches
- **Answer the Public**: Question-based keywords
- **Ubersuggest**: Limited free searches

**Paid Tools**:
- **Ahrefs** ($99/month): Comprehensive data
- **SEMrush** ($119/month): Competitor analysis
- **Moz** ($99/month): Beginner-friendly

### Keyword Selection Framework

**Evaluate each keyword**:

```
Keyword: "eco friendly yoga mat"

Search Volume: 2,400/month ✓ (Good)
Keyword Difficulty: 35/100 ✓ (Medium, achievable)
Commercial Intent: High ✓ (Buying keyword)
Relevance: Perfect ✓ (Exact product)

Decision: Target this keyword
```

**Target metrics**:
- Search volume: 500-10,000/month
- Keyword difficulty: Under 40 (for new sites)
- Commercial intent: Medium to high
- Relevance: Exact match to products

> **Vocabulary**:
> - **comprehensive** /ˌkɒmprɪˈhensɪv/ - 全面的
> - **achievable** /əˈtʃiːvəbl/ - 可实现的

## On-Page SEO

### Product Page Optimization

**Title Tag** (Most important):
```
Format: [Primary Keyword] | [Brand Name]
Example: "Eco-Friendly Cork Yoga Mat | EcoYoga"
Length: 50-60 characters
```

**Meta Description**:
```
Include: Primary keyword, benefit, call-to-action
Example: "Shop our sustainable cork yoga mat with 
non-slip surface. Free shipping on orders over $50. 
Order now!"
Length: 150-160 characters
```

**URL Structure**:
```
Good: /products/eco-friendly-cork-yoga-mat
Bad: /products/product-12345
```

**Product Description SEO**:
- Include primary keyword in first 100 words
- Use related keywords naturally
- Write for humans first, search engines second
- Minimum 300 words for competitive keywords

**Image Optimization**:
- File name: `eco-friendly-cork-yoga-mat.jpg`
- Alt text: "Eco-friendly cork yoga mat with non-slip surface"
- Compress images (under 200KB)
- Use WebP format when possible

> **Vocabulary**:
> - **meta description** - 元描述
> - **compress** /kəmˈpres/ - 压缩

### Collection/Category Pages

**Optimize for broader keywords**:
```
Page: /collections/yoga-mats
Title: "Yoga Mats - Eco-Friendly & Non-Slip | EcoYoga"
Description: Category overview (200-300 words)
Include: Benefits, use cases, buying guide
```

**Internal Linking**:
- Link from homepage to main collections
- Link from collections to products
- Link related products to each other
- Use descriptive anchor text

> **Vocabulary**:
> - **anchor text** - 锚文本（链接文字）

### Blog Content for SEO

**Content Strategy**:

**Informational Posts** (Drive traffic):
- "How to Choose the Perfect Yoga Mat"
- "10 Yoga Poses for Beginners"
- "Yoga Mat Care Guide"

**Commercial Posts** (Drive sales):
- "Best Eco-Friendly Yoga Mats 2026"
- "Cork vs. Rubber Yoga Mats: Complete Comparison"
- "Yoga Mat Buying Guide"

**Content Structure**:
```
1. Compelling headline (include keyword)
2. Introduction (hook + keyword)
3. Table of contents (for long posts)
4. Subheadings (H2, H3 with keywords)
5. Body content (1500-2500 words)
6. Images/videos
7. Conclusion with CTA
8. Related products/posts
```

**Publishing Frequency**:
- New stores: 1-2 posts per week
- Established stores: 1 post per week minimum
- Quality over quantity

> **Vocabulary**:
> - **compelling** /kəmˈpelɪŋ/ - 引人注目的
> - **CTA** (Call to Action) - 行动号召

## Technical SEO

### Site Speed Optimization

**Target Metrics**:
- Page load time: Under 3 seconds
- First Contentful Paint: Under 1.8 seconds
- Time to Interactive: Under 3.8 seconds

**Optimization Tactics**:
- Compress images (TinyPNG, ImageOptim)
- Enable lazy loading
- Minimize JavaScript
- Use CDN (Content Delivery Network)
- Choose fast hosting/theme

**Testing Tools**:
- Google PageSpeed Insights
- GTmetrix
- Pingdom

> **Vocabulary**:
> - **contentful** /kənˈtentfʊl/ - 有内容的
> - **interactive** /ˌɪntərˈæktɪv/ - 可交互的

### Mobile Optimization

**Critical Elements**:
- Responsive design (adapts to screen size)
- Touch-friendly buttons (min 48x48px)
- Readable text (min 16px font)
- Fast loading on 3G/4G
- No intrusive popups

**Testing**:
- Google Mobile-Friendly Test
- Real device testing (iOS and Android)
- Chrome DevTools mobile emulator

### Site Structure

**Ideal Hierarchy**:
```
Homepage
├── Collection 1
│   ├── Product 1
│   ├── Product 2
│   └── Product 3
├── Collection 2
│   └── Products...
└── Blog
    ├── Post 1
    └── Post 2
```

**Best Practices**:
- Max 3 clicks from homepage to any product
- Logical categorization
- Breadcrumb navigation
- XML sitemap (auto-generated by Shopify)

> **Vocabulary**:
> - **hierarchy** /ˈhaɪərɑːki/ - 层级结构
> - **breadcrumb** /ˈbredkrʌm/ - 面包屑导航
> - **sitemap** /ˈsaɪtmæp/ - 网站地图

### Schema Markup

**What is Schema?**
Structured data that helps search engines understand your content.

**Essential Schema Types**:
- **Product Schema**: Price, availability, reviews
- **Organization Schema**: Business info
- **Breadcrumb Schema**: Navigation path

**Implementation**:
- Shopify adds automatically
- Verify with Google Rich Results Test
- Check for errors in Search Console

> **Vocabulary**:
> - **schema** /ˈskiːmə/ - 架构
> - **markup** /ˈmɑːkʌp/ - 标记

## Link Building

### Why Links Matter

**Backlinks** = Votes of confidence from other websites
- More quality links = Higher rankings
- Not all links equal (authority matters)
- Natural link profile is key

> **Vocabulary**:
> - **backlink** /ˈbæklɪŋk/ - 反向链接

### Link Building Strategies

**1. Content Marketing**:
Create linkable assets:
- Ultimate guides
- Original research/surveys
- Infographics
- Tools/calculators
- Industry reports

**2. Guest Posting**:
Write for relevant blogs:
- Find: "yoga blog" + "write for us"
- Pitch unique topic ideas
- Include natural link to your store
- Target: 2-4 guest posts per month

**3. Product Reviews**:
Send products to:
- Bloggers in your niche
- YouTube reviewers
- Instagram influencers
- Industry publications

**4. Resource Pages**:
Find pages linking to similar products:
- Search: "yoga resources"
- Reach out: "I noticed you link to [X], 
  our [product] might be a good addition"

**5. Broken Link Building**:
- Find broken links on relevant sites
- Offer your content as replacement
- Tool: Ahrefs Broken Link Checker

> **Vocabulary**:
> - **asset** /ˈæset/ - 资产
> - **infographic** /ˌɪnfəˈɡræfɪk/ - 信息图表
> - **pitch** /pɪtʃ/ - 推销，提案

### Link Outreach Template

```
Subject: Quick question about [Their Article Title]

Hi [Name],

I came across your article on [topic] and found 
it really helpful, especially [specific detail].

I recently published a comprehensive guide on 
[related topic] that your readers might find 
valuable: [URL]

It covers [unique angle/data] that complements 
your article nicely.

Would you consider linking to it or sharing it 
with your audience?

Either way, keep up the great work!

Best,
[Your Name]
```

**Tips**:
- Personalize each email
- Provide value first
- Keep it brief
- Follow up once after 1 week

> **Vocabulary**:
> - **outreach** /ˈaʊtriːtʃ/ - 外联
> - **complement** /ˈkɒmplɪment/ - 补充

## Social Media for Traffic

### Platform Selection

**Instagram**:
- Best for: Visual products, lifestyle brands
- Content: Product photos, lifestyle shots, stories
- Frequency: 1 post/day, 5-10 stories/day

**TikTok**:
- Best for: Younger audience, viral potential
- Content: Short videos, trends, behind-scenes
- Frequency: 1-3 videos/day

**Pinterest**:
- Best for: Home decor, fashion, DIY
- Content: Product pins, infographics, guides
- Frequency: 5-10 pins/day

**Facebook**:
- Best for: Older demographics, community building
- Content: Mix of posts, videos, live streams
- Frequency: 1-2 posts/day

> **Vocabulary**:
> - **viral** /ˈvaɪrəl/ - 病毒式传播的

### Social Media Strategy

**Content Mix (80/20 Rule)**:
- 80% Value: Education, entertainment, inspiration
- 20% Promotion: Product posts, sales

**Engagement Tactics**:
- Respond to all comments
- Ask questions in captions
- Run polls and quizzes
- Share user-generated content
- Host giveaways

**Hashtag Strategy**:
```
Mix of sizes:
- Large (1M+ posts): #yoga
- Medium (100K-1M): #yogamat
- Small (10K-100K): #ecoyoga
- Branded: #yourbrandname

Use 10-30 hashtags per post
```

> **Vocabulary**:
> - **engagement** /ɪnˈɡeɪdʒmənt/ - 参与度
> - **caption** /ˈkæpʃn/ - 标题，说明文字

## Paid Advertising Basics

### When to Start Paid Ads

**Prerequisites**:
- Store is fully set up
- At least 10 products
- Clear brand identity
- Conversion rate above 1%
- Budget: $500-1000 minimum

### Google Ads

**Campaign Types**:

**Google Shopping**:
- Shows products in search results
- Best for: High-intent keywords
- Cost: $0.50-2.00 per click

**Search Ads**:
- Text ads in search results
- Target: Transactional keywords
- Cost: $1-5 per click

**Display Ads**:
- Banner ads on websites
- Best for: Retargeting
- Cost: $0.50-1.00 per click

> **Vocabulary**:
> - **prerequisite** /priːˈrekwəzɪt/ - 先决条件
> - **retargeting** /ˌriːˈtɑːɡɪtɪŋ/ - 重定向

### Facebook/Instagram Ads

**Campaign Objectives**:
- Traffic: Drive visitors to store
- Conversions: Optimize for purchases
- Catalog Sales: Dynamic product ads

**Targeting Options**:
- Demographics: Age, gender, location
- Interests: Hobbies, behaviors
- Lookalike Audiences: Similar to customers
- Retargeting: Previous visitors

**Budget**:
- Start: $10-20/day
- Test: 3-5 ad variations
- Scale: Increase budget on winners

### Ad Creative Best Practices

**Images/Videos**:
- High quality, well-lit
- Show product in use
- Include text overlay (key benefit)
- Test multiple variations

**Ad Copy**:
- Hook: Grab attention first line
- Benefit: What's in it for them?
- Proof: Social proof, guarantee
- CTA: Clear next step

**Example**:
```
Hook: "Tired of slipping during yoga?"
Benefit: "Our cork mat provides natural grip"
Proof: "4.8★ from 500+ reviews"
CTA: "Shop now + free shipping"
```

> **Vocabulary**:
> - **overlay** /ˈəʊvəleɪ/ - 覆盖层
> - **variation** /ˌveəriˈeɪʃn/ - 变体

## Analytics and Tracking

### Key Metrics to Monitor

**Traffic Metrics**:
- Sessions: Total visits
- Users: Unique visitors
- Traffic sources: Where visitors come from
- Bounce rate: % leaving immediately

**Engagement Metrics**:
- Pages per session
- Average session duration
- Top pages

**Conversion Metrics**:
- Conversion rate: % of visitors who buy
- Average order value
- Revenue per session

**Goals**:
- Traffic: 1000+ sessions/month (first 3 months)
- Conversion rate: 1-3%
- AOV: $50+

> **Vocabulary**:
> - **bounce rate** - 跳出率
> - **AOV** (Average Order Value) - 平均订单价值

### Google Analytics Setup

**Essential Reports**:
- Acquisition > All Traffic > Source/Medium
- Behavior > Site Content > All Pages
- Conversions > E-commerce > Overview

**Custom Goals**:
- Newsletter signups
- Add to cart
- Checkout initiated
