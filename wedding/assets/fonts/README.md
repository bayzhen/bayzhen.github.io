# Wedding poster font

`poster-songti.woff2` is a renamed, page-specific subset of Noto Serif CJK SC Regular (collection index 2 in `NotoSerifCJK-Regular.ttc`), licensed under the SIL Open Font License 1.1; see `OFL.txt`.

Generated with fontTools from the text in `wedding/poster/index.html`, plus printable ASCII. The original glyph designs and license metadata are retained. If the poster copy changes, regenerate the subset to cover new characters; system serif fonts provide the fallback.
